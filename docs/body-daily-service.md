# 日常身体后台

更新：2026-11-21。E3f-9d.7 与连接设置已获主人反馈“一切正常”。

## 本轮目标

把小智生活工具、摸头接收和联网表情接收合并到正式后台。电脑登录后自动启动，后台意外退出后自动恢复；日常入口统一为 `4311/companion`。

## 接口与数据流

- `GET /api/companion/body`：显示两路接收服务、最近设备交换、证书有效期和试播结果。
- `POST /api/companion/body`：提交 `{request_id: UUID, expression: neutral|happy}`。同一编号重试接续原命令；设备最近交换、资源和角色匹配且空闲时才创建新命令。
- 试播 → 原输出队列 → 4319 HTTPS → 设备播放器 → 原回执。使用 `body-preview:` 来源，和自然对话的 `reply-` 分开记录。画面仍由主人观察确认。
- 交接接收存档时保留设备传输序号。先停止两侧服务，核对配套配置，只提升序号水位；原生活记录继续留在正式存档。
- 摸头 → 4318 HTTPS → 原输入事务 → 原正式存档。小智继续查询相同生活与记忆。
- 常驻进程 → 读取本机配置 → 启动正式后台 → 检查进程及两路监听。退出或持续失去响应后退避重开；身份不符的端口显示冲突，配置变化提示重开。

## 依赖与边界

沿用 Node 24、Windows 当前用户、小智已加密接入点、现有 SQLite 和 E7 配套证书。配置与证书移入 `%LOCALAPPDATA%/DeskBot/companion`。固件、显示参数、角色包保持当前已验收版本。客户端自主生活按原模块继续开发。

本轮完成常驻、配置保留、证书到期提示和统一试播。设备凭证轮换接续下一模块：当前设备的令牌与信任证书仍随固件配套，电脑端更换文件需要同时更新设备。

## 验证与归档

单元与 HTTP 测试覆盖请求重试、连续试播、设备忙碌、离线、角色变化及原回执。进程联测使用隔离存档，检查重复启动、异常退出、监听失败和配置变化。现场交接前在线备份正式存档，交接后核对旧记录、小智工具与设备交换；实际重启电脑后自启和画面验收按主人时间补测。归档保留测试结果、复核和恢复入口。

## 本轮结果

正式 4311 已接管两路 HTTPS，原 4316 验收服务已停止。33 项模块／进程测试、10 项新页面检查、原记忆页 9 项回归和独立复核通过；正式服务重开前后各发送平静、开心，4 条均收到设备播放器回执。原 27,205 条记录全部保留、内容一致，SQLite 检查通过。当前用户登录自启已安装，快捷方式启动确认复用同一实例；实际重新登录后的启动按主人时间观察。
