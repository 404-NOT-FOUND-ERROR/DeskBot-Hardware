# E1.43a-7：同轮快照与单页实测

## 修正内容

A6 的 CPU 读取与同轮写前内容一致，但校验引用了较早的 bootloader 摘要，导致探针未通过。A7 改为使用本次写入前采集的快照：

1. 保存低地址 64 KiB 和跨界前 16 B，与设备身份、计划和运行目录绑定。
2. 将快照清单的 SHA-256 写入恢复日志；校验时先核对清单，再读取内容。
3. bootloader 与分区表按不可变前缀校验；含 NVS 的整页另记观测值。
4. 恢复沿用保存的计划与回退字节，兼容 A6 日志；恢复不依赖新构建或快照文件。
5. 新执行入口只接受 A7 独立构建及完整源码清单。
