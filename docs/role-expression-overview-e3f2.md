# E3f-2：角色表达总览

更新：2026-11-09 · 离线功能、测试和独立复核通过。

目标：一次看清当前角色的 29 项表达接线。每项展示语义、角色资源、当前资源、播放方式、附带动作和下一步，点击后进入现有节点编辑与前后预览。

## 设计

角色草稿 → 选中角色 → 已有逐项解析器 → 全角色报告 → 总览卡片 → 原节点编辑器。

新增 `overview(draft, catalog, reference, ...)`，返回 `deskbot.role_expression_overview/v1`。输入沿用草稿、目录、会话和时效；输出包含角色与修订号、来源、目录摘要、28 项表情及 1 项聆听状态的分析与汇总。`POST /api/role-expression/overview` 读取同一连接快照完成分析。

来源分别为 E1.18 留存快照和 USB 实时目录。共用解析器新增 `emit_command=False` 分析选项，在命令构造前返回；默认播放行为沿用原实现。总览只做分析，播放由原单表情入口重新核对后发送。聆听项显示为语音状态动画，动作显示现有绑定与事实级完成方式。

新增独立 E3f-2 页面和服务，继承 E3e 的节点、资源发布和唯一 USB 所有者。切换角色、编辑接线、切换来源或连接变化后，旧结果失效；汇总点击后生成，页面定时刷新只检查有效性。

## 验证与交付

- 单元：全量统计、候选替换、缺少接线、播放参数、动作与布局、能力、忙碌、过期、断线、跨会话和输入不变性。
- 集成：生产 HTTP 配合内存连接，确认分析只读取一次状态、生成零设备命令，沿用原来源和大小检查。
- 浏览器：默认快照、切换角色、筛选、节点往返、旧结果失效；1440、390、320 px 和减少动画设置。
- 交付：源码、简短报告、可复现测试入口与独立复核；设备安装和圆屏观察接续原实机顺序。

## 当前结果与使用

总览已接入工作台，提供全部、待处理和已匹配筛选。每项可进入原节点编辑器或前后对照预览；改接后重新核对即可看到影响。角色资源与设备播放能力分别展示，聆听仍随语音状态播放。

42 项单元及 HTTP 集成测试通过，零跳过；36 项浏览器检查通过，覆盖 1440、390、320 px、减少动画、改接、重连、状态过期与迟到回复。使用生产页面和 HTTP，设备连接由内存对象提供。另有 10 项历史来源回归与项目交付检查通过。[离线记录](../artifacts/deskbot-studio-e3f2-20261109/offline-validation-3.json) · [交付记录](../artifacts/deskbot-studio-e3f2-20261109/result.json) · [独立复核](../artifacts/deskbot-studio-e3f2-20261109/peer-review.json)。
