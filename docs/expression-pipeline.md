# 表情制作与替换

目标：在一个工作台里看清真实的「触发 → 语义 → 素材 → 圆屏资源 → 安装版本」，上传后生成当前固件可读取的资源，安装后保留上一版。

## 接口与处理

工作台 `/expressions/`，本机接口 `/api/expressions/`。项目保存源文件、修订、逐语义绑定、镜像、EAF 帧率、生成日志和产物摘要。GIF 使用原帧时长，EAF 由主人指定帧率；先等比平滑缩放并居中到 360×360，再按 25 fps 时间轴采样。镜像为素材选项，默认关闭，可手动修改。编译时对上传整帧图像执行真实水平翻转，不能依赖眼层播放器标志。

位图动画编译为现有 DFM1 的彩色图层，复用当前播放器的进入、完整主体、收尾、途中切换与取消。原分层动画保持左右眼独立时序；导入的整帧动画保持其原画面。困倦和疲惫共享素材，播放规则各自延续。事件到语义的现有映射保持，资源替换按目标语义生效。

每次构建从明确的已安装基线派生，保留未替换表情、公共字体、唤醒模型及聆听条；核对 DFM 边界、资源往返和 8 MiB 容量。输出真实预览、App、资源、摘要与安装清单。素材更新复用配套 App；播放逻辑更新才重新编译 App。

安装复用已有事务：确认头部身份、核对当前 Flash、保存现场 App/资源和 NVS → 成对写入相同 App 与新资源 → 回读 → 启动核验 → 主机采用新角色图。App 字节不变，NVS 保留。安装线程随工作台关闭一同等待；意外中断留下明确的恢复任务。只有设备启动和主机配置均核验后才恢复小智；恢复失败时保留现场和停止状态。

上传 GIF、EAF 或 PNG 会把完整画面放进一个彩色动作层；它保留当前语义的入口、时长、收尾、途中切换和取消，无法从扁平图片自动恢复左右眼图层或增加语义映射。已接入的硬件事件继续沿原入口进入播放器；其他新硬件触发需另做固件集成。

## 使用

2026-11-27：工作台已同步闹钟修复 App 与原 r8 资源，当前组合引用为 `tmp/layered-face-reference-20261127-alarm/`。隔离生成并核对过安装包，确认后续替换素材会继续使用新 App。这个引用仅用于读取基线；设备恢复使用闹钟模块保留的真实安装现场。

打开 [表情制作](http://127.0.0.1:8782/expressions/)，选目标表情 → 上传 GIF/EAF/PNG → 调整镜像（EAF 可调帧率）→ 保存素材绑定 → 生成安装包。圆屏预览与下载包读取同一份 DFM；可点其他表情测试途中切换，点“收尾”测试取消。生成前预览显示当前安装素材。

连接页接通 COM4 后点“安装到桌宠”，完成回读与启动核验后观察圆屏，再检查菜单、对话、三连触和睡眠唤醒。安装成功后出现“恢复上一版”；中断后重新打开工作台会出现“恢复安装前版本”。任意新增硬件触发与自由编排不在首版范围，节点显示当前真实语义绑定。
