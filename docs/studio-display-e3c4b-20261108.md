# E3c-4b 显示查询

目标：在已验收 E3c-3b 上增加显示状态查询，作为普通交互测试版。

## 实现

工作台 → 原 USB 会话 → `display` 查询 → 固定大小状态快照 → 查询结果。沿用原接收任务、10 ms 间隔和 4,092 B 显示分块；表情请求与目录在后续候选逐项接入。

构建入口为 `build-studio-stable-ladder.py --stage display`。先核对关闭版与 E3c-3b 的可执行内容，再核对开启版功能、容量、栈和保护产物。原生测试直接编译候选源码，覆盖主页、菜单、说话、无会话和持续输入。

## 安装与恢复

部署入口 `deploy-e3c4b-display.py` 提供 `prepare / check / prepare-live / install / recover / restart`。离线准备读取已保存 E3c-3b 快照；现场准备重新读取前缀并核对全片，保存当轮 NVS 与 App 擦除范围。安装只写 App，完整回读后启动。恢复沿用已有 App 事务，读取同轮备份与持久日志，可在候选删除后单独运行。

输入固定为已验收 E3c-3b、显示层构建报告、原生测试报告与 COM4 设备身份；输出为安装计划、回读与启动结果。候选和恢复镜像分别核对长度与摘要。安装后保持测试版运行，主人方便时统一反馈。

## 验收

菜单往返 5 次；摸头 3 次；睡眠再唤醒；一次对话中和说完后切菜单。开发者核对显示查询与日志，主人确认圆屏和操作效果。通过后继续平静表情及回执，再接真实资源目录。
