# 小智接入生活愿望 · 4c

2026-11-22。共同记忆已实机通过。现在让主人问一句「你最近想试试什么？」时，听见客户端已保存的愿望和它的生活来由。主人仍在客户端选择尝试、稍后或拒绝。

## 接口与数据流

客户端的实际经历 → 原角色愿望与主人回应 → 小智原近况工具 `deskbot_get_recent_life` → 桌宠开口。沿用同一个体、原生活存档与小智音色。愿望的形成、状态和试做继续由客户端管理。

工具增加 `wish`，返回当前仍有生活依据、等待讨论的一份愿望，包含 `status: proposed`、`label` 和根据实际经历生成的 `reason`。两份同时符合时，优先最近提出的。暂无待讨论愿望时返回 `null`。读取异常时省略该字段，原近况照常返回。

主人回应后沿用客户端的记录。选择「稍后」后，这份愿望退出当前语音候选，仍可在客户端回看。试做准备、阶段采用和实体安装分别沿用自己的记录。当前外壳只读取工作台的已确认安装。

## 验证

独立 SQLite 使用已准备好的生活经历，核对原接口产生的愿望能被小智工具读到。用原客户端接口选择「稍后」，再次查询确认它退出候选。覆盖无愿望、依据不足、另一角色、仍可查询真实近况与工具读取异常。正式存档出现首份待讨论愿望后，再听测桌宠的说法。

## 本轮结果

65 项自动检查通过。独立服务通过小智同款 MCP 协议读取了保存的愿望与来由；使用原客户端接口选「稍后」后，语音查询结果为空，原近况和角色状态正常。正式存档暂无待讨论的愿望，本轮交付为本机代码与隔离联测。
