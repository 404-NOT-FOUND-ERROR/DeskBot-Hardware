原工作台地址为 `http://127.0.0.1:8780/#shells`。新版通过本机 HTTP 读取状态、提交原设备命令；原表现协调器处理客户端和安装请求。设备连接的启停仍在原服务操作，退出新版验收页保留原连接。设备端可从角色页选回上一表现。
