# 工作台统一视觉与动效

目标：总览、角色、外壳、表达编排、素材、连接、发布和采样使用同一套界面语言。已有功能在同一个工作台继续使用。

## 设计

- 浅色基底、蓝紫主色，薄荷与暖杏用于状态和提示；深色主题采用同一套语义变量。
- 统一字体层级、页面宽度、间距、面板、按钮、表单、标签和焦点。节点保留各类含义，画布与预览使用相同边框和强调色。
- 页面切换采用分层淡入与小幅位移；导航选中背景平滑跟随。卡片选中、节点反馈、折叠展开、弹窗与通知使用统一非线性缓动，动作及时响应快速连续点击。
- 轮询只更新状态，操作触发动效；编辑草稿、焦点和节点播放连续保留。系统选择减少动画时，界面即时完成切换。

## 实现接口与数据流

`既有业务状态 → 既有页面渲染 → 统一样式变量 / DeskBotWorkbenchMotion → 浏览器视觉反馈`。

样式在最终集成构建器中加载，角色、外壳与采样模块改用语义变量。动效模块提供 `init()`、`navigate(render)`、`afterRender(container, route)`、`arrive(container)` 与 `state()`；沿用现有路由回调，用 Web Animations 实现内容分层切换。连续切换取消上一段，折叠按实际高度过渡，退出后释放动画。

依赖：现有 HTML 构建器、页面 DOM、浏览器动画 API 与 `prefers-reduced-motion`。接口请求、角色绑定、预览时钟和设备调度继续由原模块负责。

## 验证与归档

浏览器检查所有页面的深浅主题、桌面与窄屏、真实过渡中间态、快速切换、折叠、草稿与焦点、减少动画以及零实机命令。回归角色、外壳、后台服务与采样流程，另由 AI 审核。截图和结果归档，本轮完成后更新主线与后续管线。

## 结果与接续

统一了 9 个页面的主题、标题、面板、表单、节点和操作反馈。导航背景平滑跟随，内容分层进入，折叠支持中途反向；弹窗、通知及深浅主题使用同一套缓动。减少动画即时完成，轮询保留草稿、焦点与预览。

160 项视觉与动效检查、156 项已有浏览器回归、56 项单元/HTTP 测试通过；独立 AI 完成 71 项检查。复核发现的深色悬停对比度和有数据时的窄屏溢出已修复。结果见 [本轮归档](../artifacts/workbench-visual-system-20261116/report.json)。

视觉系统继续复用。A/B 模拟基线与主人安装确认已有后续交付；当前先完成统一交流、真机联网语音与常驻日常版，见[整体评估](project-readiness-20261118.md)。真实壳完成后补拆装校准，自动匹配按实测逐步启用。
