# E3f-6：节点接入实机

更新：2026-11-10。设备为已验收的 E3f-5 / E1.45；本轮切换电脑工作台，沿用当前固件。

## 接入设计

数据流：角色接线 → 核对素材、布局和实时目录 → 点击节点播放 → 原 USB 所有者 → 应用主循环 → 原播放器 → 关联设备回执。

接口沿用 `body/ports`、`body/connect`、`body/disconnect`、`studio/state`、`studio/command` 和 `role-expression/resolve`。新服务使用端口 8776；先停止 8775 的 USB 观察，再连接 8776 的 COM4、启用查询并读齐 37 项目录。请求绑定当前连接、设备、启动、会话和目录。

依赖为 E3f-6 已审核代码、生成页面、布局登记、E1.45 目录及 E3f-5 验收记录。先核对既有测试与当前输入；生成来源中仅文档变化时保存旧报告，再更新生成报告并核对页面字节一致。

节点替换先改变角色草稿和电脑预览；当前设备目录匹配时才能播放。草稿与已装资源不同，工作台提示发布；撤销后恢复原接线与播放。取消、切换页面或修改接线会结束本次等待。

恢复电脑入口：停止 8776 的 USB 观察，在原 8775 工作台重新连接 COM4。设备仍使用本轮已验收固件。

## 验证

- 自动：来源摘要、页面可复现、服务健康、当前固件身份、37 项真实目录、三项能力，以及节点请求与设备回执。
- 界面：进食完整画面、害羞双眼；替换后旧节点断开、新节点连接，撤销后恢复；连续点击使用不同请求。
- 主人：从节点播放进食、平静、害羞，再测试菜单、对话、摸头和睡眠唤醒。
- 归档：保留原测试与回读报告，本轮现场结果和另一位 AI 的审核另存。
