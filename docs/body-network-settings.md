# 日常连接：服务地址保存与恢复

2026-11-21。接续身体联网合并版，实现服务地址设置、持久保存和后台切换。换电脑或热点地址后，沿用同一 App 即可更新连接地址。E3f-9d.7 与[工作台设置](body-network-workbench.md)已安装就绪，圆屏和日常操作统一验收。

## 接口和数据流

电脑设置工具 → 原 USB 会话协议 → 设备配置模块 → 独立 NVS 项 → 原单网络任务 → 摸头／表情 HTTPS。

| 操作 | 定义 |
| --- | --- |
| `net-get` | 读取主机、两端口、配置修订和任务已采用的修订 |
| `net-set:修订:主机:摸头端口:表情端口` | 按当前修订保存，两端口不同；相同配置重试返回原修订 |
| `net-reset:修订` | 保存恢复出厂地址的选择，同样保留修订 |
| 回复 `deskbot.body_network/v1` | 关联设备、启动、会话和请求编号；分别报告保存结果、配置修订与已采用修订 |

沿用原会话身份、30 秒租约和限流。主机支持私人 IPv4 或最多 63 字节的 DNS 名称，端口 1–65535。配置仅保存地址与端口，约 80 B；原两路凭证、证书及小智网络设置继续使用各自原配置。

USB 设置任务核对并提交 NVS，提交成功后发布新配置。原网络任务在当前请求结束后切换两条 URL，保留触摸队列和表情回执，再立即连接新地址。HTTP 运行期间使用的字符串由网络任务独占。UI、触摸和角色播放器沿用原实现。

默认地址来自构建配置。启动读取 `deskbot_net/profile`，有效记录恢复保存值；缺失或格式不符时采用默认地址并给出读取状态。旧修订修改返回当前配置。打开存储失败返回 `save_failed`；写入或提交出错返回 `save_uncertain`，本次运行继续使用原地址并暂缓后续保存。重启后读取完整有效记录，再以实际修订接续。正常重试不重复写 Flash。

配置与构建位于 `tmp/body-network-settings-20261121/live-hotspot2`，离线安装／回退计划位于 `tmp/e3c-live-20261121-wifi-network-off2`。回退目标为当前表情专项版，其自身回退继续指向已验收的摸头版。待用后台配置单独保存，实机时先核对实际网络，再安装和启用。

电脑工具 `scripts/configure-body-network.py` 默认预览；指定 `--port` 才打开串口。实机使用前先释放工作台串口，它等待设备 hello、核对设备与 App 摘要，保存前读取当前修订，保存后回读并报告任务是否已采用。HTTPS 实际连接和执行另核对回执。

```powershell
python scripts/configure-body-network.py set --profile tmp/body-network-settings-20261121/live-hotspot2/expression --host 10.114.1.176
```

上述地址是本轮构建默认值。换网时按电脑的新私人地址设置，同时更新客户端监听地址；原配套证书和凭证随同一服务继续使用。图形入口已完成，凭证更新接续下一步。
