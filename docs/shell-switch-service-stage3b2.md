# 阶段 3b2：自动换角调度与启停

目标：在“我的外壳”加入持续运行的自动换角服务，显示识别、目标角色、实际首帧与保存进度。本轮沿用内存设备验证完整服务。

## 设计

`已验证登记与确认关联 → 服务调度 → 原 USB 所有者快照 → M2 / 换角适配器 → 原命令入口 → 回执 → 页面状态`。

- `ShellSwitchService` 由工作台服务持有，每 100 ms 调度；浏览器每秒只读取状态。新服务默认停用，点击开始后才进入运行。
- 配置选择一个采样项目，固定设备、档案、完整角色和关联摘要。启动核对原日志与登记来源；配置变化后显示待确认，重新开始时采用新版。
- 连接所有者提供原子 `shell_inputs()`：`control / magnetic / motion`。磁场事件沿用原接收时刻；动作状态为 `true / false / null`，未知时等待确认。现有 USB 适配器提供状态与磁场，动作来源在 3b3 实机接入时核对。
- 暂停立即停止新切换，已交接请求继续查询到首帧和保存；重试由页面明确发起。重连先读取设备，重新积累样本。重启服务后点击开始继续。

配置锁顺序沿用“采样 → 角色 → 关联 → 调度器 → 连接所有者”。核对配置与交接命令在同一次调度内完成，保证版本一致。停止、重试和命令交接串行处理；服务关闭时先退出调度，再释放连接。

## 接口与页面

`GET /api/shell-runtime/state` 返回服务代次、项目选项、运行阶段、原因、识别、目标、设备实际角色、保存结果和最近回执。页面轮询只更新运行卡片，保留正在编辑的角色与外壳表单。

`POST /api/shell-runtime/start` 接收 `session_id / expected_generation`；`stop`、`retry` 接收 `expected_generation`。代次冲突返回最新状态。沿用本机来源校验、JSON 和请求大小限制。

运行卡放在外壳设置与离线演练之间，集中显示“开始 / 暂停 / 重试”。登记完成后选择对应项目开始；准备项未完成时直接显示下一步入口。

## 测试与后续

单元测试覆盖启停、重复点击、版本冲突、断线、样本时效、转动、配置更新、保存失败和服务退出。集成通过真实 M2、生产主机协议和内存设备，验证后台持续运行及已交接请求收尾。HTTP 与浏览器检查轮询、表单保留、窄屏、错误恢复和零真实设备命令，由另一 AI 复核。

接下来：3b3 接续采样、确认实际关联及动作状态来源，验收 A/B 自动换角；之后接人格与声音。
