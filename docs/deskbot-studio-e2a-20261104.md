# DeskBot Studio · 阶段二第一步

2026-11-04。统一工作台入口，先把链路、素材与操作整理清楚。

## 使用方式

打开[公开版](../artifacts/deskbot-studio-e2a-20261104/index.html)。本机完整预览位于 `tmp/deskbot-studio-e2a-20261104/index.html`，包含已选害羞候选的动态画面。两版均可直接打开，草稿可以互相导入。

| 页面 | 一眼看到什么 | 可以做什么 |
| --- | --- | --- |
| 总览 | 外壳到身体的六步链路、版本记录、当前角色和圆屏效果 | 切换表情、对照设备资源快照与角色草稿 |
| 表达编排 | 入口 → 语义 → 动画，另列身体动作 | 拖动节点、替换动画、对照原连接、撤销与恢复、逐帧播放 |
| 素材库 | 19 个动画与 5 个现有动作 | 搜索、筛选、看预览及关联语义 |
| 角色 | 默认表达与两个标注清楚的示例草稿 | 复制、改名，分别保存表情映射 |
| 发布 | 映射差异、资源容量和后续步骤 | 导出草稿与发布审阅清单 |

建议从“表达编排”的“害羞”开始，点击“替换动画”选择新候选。原 Happy 节点移到对照分支，新候选接入当前草稿。回到总览，可切换查看两种效果。

界面使用圆屏预览、曲线连线和渐进展开；页面、弹窗与节点使用缓动衔接。支持浅色、深色、窄屏，以及系统减少动效设置。

## 数据与架构

```mermaid
flowchart LR
    S[已核对的资源与源码] --> C[统一目录]
    C --> V[总览与素材预览]
    C --> E[角色表达草稿]
    E --> G[节点接线与前后对照]
    G --> R[差异与容量审阅]
    R --> H[导出发布清单]
    H --> N[下一步：构建与包审计]
```

目录汇总 29 个语义、18 个当前资源、1 个新候选、56 条源码入口及 5 个身体动作。动态入口注明由服务选择情绪，固定入口展示实际关联。动作目录展示当前官方能力及引用关系。

草稿遵循 [`deskbot.studio_draft/v1`](../protocol/deskbot-studio-draft-v1.schema.json)：记录目录摘要、修订号、角色和语义映射。纯编辑核心负责校验及撤销；页面负责交互和预览；浏览器按目录版本保存草稿。媒体采用可见区域加载和有限图集缓存。

发布页区分两类容量：精确匹配 E1.45 的单语义方案，使用已审计的实际包大小 5,981,260 B；其他组合显示预估，保留现有包成员并合并新增资源。8 MiB 活动分区的发布软上限为 7 MiB。

设备区展示已保存版本：E1.42 App、E1.40 bootloader、E1.18 资源。工作台当前处理电脑上的创作草稿；E1.45 候选处于待部署状态。
