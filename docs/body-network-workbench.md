## 流程与接口

设备连接页 → 本机连接路由 → 独占 USB 维护 → 原 `net-get/set/reset` → 保存与任务采用回读。维护前结束原 USB 观察，完成后重新启动同一端口的观察，实际连接由设备状态确认；原角色与表情控制按用户操作启用。

| 接口 | 内容 |
| --- | --- |
| `GET /api/body/network` | 设置、当前维护任务、电脑两路 HTTPS 与小智桥接状态；读取页面不访问串口 |
| `POST /api/body/network` | `request_id`、`action=get/set/reset`、头部端口；set/reset 附带页面读取的 `expected_revision`，set 包含主机与两端口 |
| 后台结果 | `running/completed/failed`；分别显示配置修订、任务采用修订及服务探测结果 |

页面轮询不覆盖正在编辑的地址，提交期间固定本次任务；重复请求编号接续原结果。服务状态只表示电脑接口可达，小智状态表示生活工具连接；圆屏和发声由实机观察确认。
