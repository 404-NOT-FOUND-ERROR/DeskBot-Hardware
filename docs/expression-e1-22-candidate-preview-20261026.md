# E1.22 表情候选前后对照

E1.22 把 E1.18 记录映射与 E1.21 离线候选放在同一页面，供人直接比较旧、新动画，并把语义节点到 EAF 资源的边界清楚画出：旧 `surprised → shocked.eaf` 边标为待断开，候选 `surprised → Happy.eaf` 边标为新建连接。

打开[对照工作台](../artifacts/expression-e1-22-candidate-preview-20261026/index.html)。两侧动画都可同步播放、暂停、逐帧前后查看，并调整预览速度。工作台使用与 E1.19 相同的 `eye_anim` 圆屏合成参考布局。

素材来自 E1.19 内的官方 EAF 解码帧图集：`shocked.eaf` 34 帧、`Happy.eaf` 42 帧，均以 20 FPS 循环。它们是官方资源解码图像，不是设备实拍；E1.21 官方 C 播放器主机测试通过也不等于 LCD 实机观感已验收。

本阶段只生成静态离线页面和报告，没有访问设备或串口，没有构建/修改固件，没有改变索引或资源包，也没有部署授权。候选部署仍需单独确认；之后只考虑本体 assets 分区，并执行完整回读及实机回归。

用户已完成视觉审阅并选择保留当前 `shocked.eaf`。选择记录位于本目录的 `selection-record.json`；它记录的是视觉决定，不改变 E1.18 映射，也不授权部署或刷写。
