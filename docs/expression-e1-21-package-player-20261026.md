# E1.21 候选包与官方播放器审计

E1.21 将 E1.20 的映射草稿应用到 E1.18 实际资源包，并对重打包候选运行官方 Espressif C EAF 播放器主机测试。公开结果和可视化见 [审计页面](../artifacts/expression-e1-21-package-player-20261026/index.html) 与 [机器可读报告](../artifacts/expression-e1-21-package-player-20261026/report.json)。

本轮提案是把 `surprised` 从 `shocked.eaf` 接回 `Happy.eaf`，恢复 E1.13 的原始映射。真实候选为 5,538,349 B，29 个成员中只有 `index.json` 改变；所有 EAF payload 均逐字节保持，候选与 E1.13 资源包逐字节相同。它比 E1.18 当前包少 2 B，距离 6,144,000 B 分区上限还剩 605,651 B。

`Happy.eaf`（42 帧）和 `shocked.eaf`（34 帧）都通过 C 播放器逐帧像素、缓冲区保护、元数据帧安全拒绝、停止后重启、重复重载清理以及循环/非循环计时器检查。E1.18 原包保留为精确回退，恢复索引后重新打包与原包逐字节相同。

| 闸门 | 结果 |
| --- | --- |
| E1.20 映射输入、E1.18/E1.13 包锚点 | 通过 |
| 单成员映射差异与分区容量 | 通过 |
| 官方 C 播放器用例 | 通过 |
| E1.18 精确回退与 E1.13 精确候选 | 通过 |
| 设备部署授权 | 待单独决定；当前 `deployment_eligible=false` |

全程没有访问串口/设备，没有构建或修改固件，没有改动 C61、NVS，也没有写入设备。主机播放器检查不能代替圆屏实机观感、UI 并发或运行时表现验收。私有候选包和播放器构建留在本机 `tmp/`，未发布二进制。
