# 表情连续性 r8

本轮沿当前 E3f-9d.7 日常固件更新画面。小智、语义事件、C61 动作映射、字幕、菜单、触摸和睡眠入口保持现状。困倦 `sleepy` 与疲惫 `tried` 共用疲惫素材；持续/单次规则仍由各自语义决定。`tired` 作为显示端同义词适配到 `tried`。

## 设计与接口

固定本机 480 母版 AFM 哈希 `f97deb06407f1549c142e81da1455a9380c9649f7fda74eff31ac21ea565aa7e`，复制到 `assets/layered-face/continuity-20261123/`。经平滑缩采样生成 360×360 DFM1、角色目录和 8 MiB 资源分区。r7 源与安装材料保留。左右眼时序、逐眼瞳孔裁切、完整主体及末姿态收尾由原播放器执行。

DFM1 的保留字 offset 48 使用位 0 表示逐眼裁切、位 1 表示末姿态收尾；0 保持旧包行为。目录别名共用关键帧范围，不复制动作。解析器边界按新密集帧扩展，仍校验长度、索引、坐标和游程。`Request/Replay/Cancel` 接口不变；原 Emote/GFX 显示锁、计时、局部刷新及 PSRAM 工作区不变。

镜像按画面共享：调整「疲惫」同时应用于困倦入口，冲突设置在打包时提示。播放时序仍按语义分别处理。母版 AFM 与目录均固定哈希，原有语义到 C61 的动作映射继续由原事件入口执行。

旧 `listen.eaf` 继续由 `SetStatus` 管理。仅对 `listen_anim` 启用白色覆盖合成：先重画当前脸，再以灰度覆盖率混合白色波形；纯黑透出背景，字节交换留到输出。帧绘制不调用情绪或身体动作入口。
