# 摸头反馈核对

2026-11-19。主人反馈：触摸头顶时绿色 LED 闪烁，桌宠没有明显回应。

当前设备回报 E3f-9d.3 的固件摘要，摸头源码与该版冻结源码一致。现有规则是：主页待机时，1.5 秒内触摸并松开三次，发送“我在摸你猫头”的唤醒信息，由小智回应。长按和单次触摸没有独立反馈。当前只为第一个触摸通道注册按钮回调。

核对顺序：待机 → 三次轻触 → Touch 日志 → 唤醒日志 → 小智回应。分别记录设备收到信号、识别手势和实际回应。

使用现有 COM4 本体和小智云。原 USB 所有者 8780 暂时交出串口，只读采集完成后恢复观察。记录放在本轮独立目录；核对结果用于确定后续身体反馈的实现。

同点三连触、左右各三连触均无回应。日志有一次右滑，按下、三连触和唤醒各 0 条。先查两路电极到按键判定这一段。板上 LED 由现场观察，按键由固件日志核对。

诊断版从 E3f-9d.3 独立构建。GPIO7、GPIO6 每 500 毫秒各读取一次，记录原始值和按下／松开累计数。原始值来自现有触摸驱动，累计数来自现有按键事件。采样在低优先级任务执行，按键回调只累加。继续沿用 5% 按键阈值和待机三连触唤醒规则。

构建核对 App、配置与保护区，COM4 仅更新 App，保留同轮回退镜像。实机依次采集静置、在闪灯位置按住约 3 秒、松开约 3 秒。按两路变化和按键事件判断下一步是检查感应路径、调整阈值，还是接入已有按键事件。
