# 固件与客户端架构

## 物理分层

```text
磁吸外壳 / 配件
        ↓
底座 C61：磁场采样、开关事件、步进电机、回零、UART
        ↓  AA55 帧
本体 S3：UART 事实镜像、官方 Agent/DOA/摸头/表情/显示、电源状态
        ↓  只读身体事实
电脑客户端 / 网关：角色登记、人格、音色、口癖、记忆、DeepSeek、ASR、TTS
```

S3 和 C61 是两个独立固件，分别有独立构建目录、分区和串口。公开仓库不会把它们合并成一个可误刷的镜像。

## 所有权边界

| 能力 | 当前所有者 | 增量原则 |
| --- | --- | --- |
| 语音、双麦 DOA、摸头、睡眠/唤醒、官方表情 | S3 官方应用 | 先保持不变，只镜像事实 |
| 电机、回零、磁场和滑动开关 | C61 底座 | 先只读诊断，再单独发布改动 |
| UART 拆包、连接状态、机械状态 | 官方底座控制组件 + S3 镜像层 | 不重复实现第二套流式接收器 |
| 外壳识别 | S3 磁场快照/档案模块 | 置信度和未知状态必须显式输出 |
| 人格、音色、口癖、TTS 和长期记忆 | 电脑客户端/网关 | 不写入固件密钥，不让固件替代 Agent |
| 表情和动作预览 | 离线工作台 → 客户端 | 预览不代表真实播放，真实替换另设闸门 |

## 事件与遥测

在研究增量明确启用且 C61 实机确认后，高频 `0x06` 磁场采样才进入遥测和外壳识别，不直接刷事件列表；状态变化才进入最多 24 条事件环。`0x06` 不是已确认的官方默认输出，不能仅凭上游源码中的内部传感器读取就宣称本体能够收到 XYZ。连接、机械状态、磁吸滑动、配件、配对、校准和动作完成都有稳定的语义名称，便于未来网关消费。

任何新功能都必须先有离线协议测试，再决定是否需要 C61 或 S3 的固件改动。
