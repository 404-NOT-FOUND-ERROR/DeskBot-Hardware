# 统一交流运行入口

日期：2026-11-18。第一步已完成电脑端联测。[文字体验](http://127.0.0.1:4315/conversation)使用原安装和聊天存档的独立副本，接 DeepSeek 真实回答。设备 Wi-Fi 语音接续下一步。

## 接口与数据流

`原安装同步 → 原 SQLite → 回合安装快照 → 原聊天与提示词 → DeepSeek → 原聊天记录和输出队列`。

- `startConversationService({clientRoot, database, sourceId, configPath, voiceCatalog, now, port})` 组合原服务、登记、安装接收器和采用解析器。
- 保留 `/api/chat`、`/api/chat/history`、`/api/outbox` 和安装同步；新增同源文字页 `/conversation` 和只读 `/api/integration/status`。文字页使用同一个体与形态，桌宠表达仍通过工作台的设备入口发送。
- 启动器显式传入源码目录、存档、安装来源与模型配置。源码清单核对已验证的客户端快照，配置密钥只从本地原文件读取。
- 每回合冻结安装编号和配置。重复请求、重开恢复沿用原回答及配置，换壳保留原个体和聊天记录。未配置人格或音色沿用原设置。

Node 24、原客户端 `0d8d4c5 + 4b1a 恢复 + 形态采用` 的固定源码、现有安装接收器与 DeepSeek 配置。运行源码从已验证副本生成独立快照；历史基线和客户端在研目录保留原内容。

现有存档为实验范围，本轮继续原世界推进方式和生活开关，交流时间使用当前时钟。统一语音、实时生活与常驻部署分别接续。当前 A/B 空人格、未配置音色如实显示；文字完成与设备播放分别记录。
