# E3f-9b：统一角色编辑与发布

日期：2026-11-12。目标：原角色和圆团共用角色配置、资源镜像选项、节点预览和生成包。E3f-9a 实机验收待主人方便时继续，本步在电脑完成。

## 数据与接口

素材目录 → 两角色草稿 → 表情节点预览 → 角色图、布局清单和 EAF 打包 → 解包逐项核对与容量报告。

草稿 `deskbot.role_pack_draft/v1` 保存目录摘要、所选角色、两角色的六项日常语义，以及资源镜像覆盖。每项表达引用一份已登记的完整动画或进入/持续/退出三段组合，记录帧率和循环。系统聆听、旧索引与原资源沿用 E1.45。

新增 `GET /api/role-package/catalog` 返回素材与初始草稿；`POST /api/role-package/generate` 接收完整草稿，返回报告与固定文件下载地址。草稿在浏览器单独保存，支持撤销、重做、导入导出。所选编辑角色只影响编辑位置；包的默认角色沿用原角色，手动启用接续 E3f-9d。生成后可核对两角色的实际引用。

包内 `deskbot-roles.json` 保存角色图；`deskbot-layout.json` 沿用 E3f-9a 格式，`role_id` 使用包编号 `role-pack`，角色图引用该清单及摘要。相同内容和布局可共用资源；布局不同则分配独立文件与物理区间。资源名最多 31 字符，布局清单最多 64 项、32 KiB。

## 预览与边界

- 同一资源默认镜像来自素材登记，可手动纠正或恢复自动；资源节点直接显示选项。
- 原角色在已登记的单段动画之间替换，圆团在完整三段组合之间替换，两者使用同一编辑界面。跨播放类型的混合编排接续设备调度阶段。
- 单段支持循环或播完停在末帧；三段当前固定持续循环，切换时完整退出后进入下一表情。可调帧率为 1–60。三段的全部片段、同角色各表情的共享姿态采用一致镜像，保证变换后接点相同。
- 角色包包含完整引用；重建目录、布局和图后再次比较。旧资源逐字节保留，新增文件只含实际选用素材和配置。
- 实际包遵守 7 MiB 建议线与 8 MiB 分区；报告列出原包、新 EAF、配置、剩余空间。生成包要求后续设备角色图/切换能力，设备安装在 E3f-9c/d 完成。

## 依赖与验证

复用 E3f-8 服务与界面、Grok 片段和解码图集、镜像像素绘制、旧资源打包器与 E1.45 基线。新模块负责统一模型与打包，原 USB 模块保持原入口。

单元测试覆盖默认转换、表达替换、镜像共享与隔离、速度/循环边界、接点、重复资源、非法引用与容量。集成测试执行真实 HTTP 生成、下载、解包和草稿对照，并确认零设备命令；浏览器测试覆盖两角色编辑、逐节点预览、保存、撤销与生成。代码和文档经独立 AI 复核。

完成后接续：设备三段播放与打断恢复 → 手动角色切换与保存 → 换壳自动切换 → 人格、声音与动作。
