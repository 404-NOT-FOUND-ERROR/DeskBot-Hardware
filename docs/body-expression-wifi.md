# 联网表达 · 首个闭环

2026-11-21。目标：客户端已有事件产生“平静／开心”输出，通过 Wi-Fi 交给当前角色播放，并把执行结果记回原输出队列。实际网络版已安装，平静与开心的真实下发与播放器回执通过，圆屏观察和日常回归待主人验收。

## 接口与数据流

`原事件／交流 → 原输出队列 → 专用 HTTPS → 本体应用队列 → 原角色播放器 → 原输出回执`。

客户端增加可选的 `DESKBOT_EXPRESSION_WIFI_CONFIG`。配置绑定设备、固件、个体、角色图、当前角色和原队列的 `role_revision`（整数或 `null`）。首轮使用独立 HTTPS 端口、证书与凭证，与摸头接收器同进程运行。原本机服务与 SQLite 继续由一个进程持有。

| 接口 | 约定 |
| --- | --- |
| `POST /api/hardware/expression/exchange` | 设备报告身份、启动编号、运行毫秒、角色图、当前角色、选择代次、可播放状态与上一条回执。每次最多返回一条命令 |
| 命令 | 固定有界文本：版本、原命令编号、递增序号、启动编号、本次查询运行时间、有效毫秒、角色图、角色、选择代次、表情。只接受 `neutral / happy` |
| 回执 | 原命令编号、序号、`dispatched / busy / interrupted / expired / rejected` 和固定原因。`dispatched` 表示已交播放器；画面由主人实测 |

设备从自身发起 HTTPS，复用原 Wi-Fi 和时钟。客户端先持久保存命令与启动绑定，再发送；设备按递增序号防重，回执丢失时重复提交原结果。服务重开继续原命令；设备重启后旧在途命令结束为结果未知，下一条绑定新启动。命令最晚在原入队 30 秒后结束，单次设备执行窗口最多 3 秒，网络耗时计入有效期。

客户端在分页前筛选设备、个体、输出种类与角色版本。首环消费原聊天的 `reply-` 表情输出；独立生活事件在客户端接续。配置启用后，这部分命令由 Wi-Fi 消费者领取，USB／WebSocket 继续处理其余队列。表情原始记录保留，重连沿用原编号。角色图与当前角色取试用配置，设备报告与执行前均核对；配置变化生成新试用配置。

## 设备调度

网络任务读取有界角色镜像，不读取 LVGL 对象。角色镜像由原显示所有者更新；播放通过 `Application::Schedule`，执行前再次核对主页、空闲、角色与有效期。USB 控制会话占用时暂停网络表达。锁只保护复制和状态，不包住调度、网络或播放器。

网络表情直接调用原角色播放器，沿用素材镜像与过渡。原 `SetEmotion("happy")` 同时下发底座动作；本接口的输出范围为画面，底座动作由后续独立命令接入。睡眠使用原播放器的阻塞状态，主页与语音使用原所有者镜像。

本轮表达 App 从已验收 E3f-9d.4b-touch 派生，Wi-Fi 摸头试用包单独保留。主人稍后验收期间，[合并版](body-wifi-combined.md)先完成离线开发和安装准备；正常语音继续小智。显示、资源、分区表、模型和 bootloader 沿用现有版本。
