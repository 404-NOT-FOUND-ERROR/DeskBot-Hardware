# 主人确认安装

目标：主人换好外壳后，从“我的外壳”确认当前实物；工作台核对内容，在主页空闲时切到对应表现，分别显示首帧与保存结果。记忆、关系和自主生活由客户端延续。

2026-11-17：设备表情采用流程已通过离线测试与真实 USB 实机验收。A → 圆团、B → 原有角色的画面和保存正常，菜单、对话、摸头与睡眠唤醒全部正常。客户端人格与音色采用继续联合接入。

## 流程与数据

`选择已关联外壳 → 确认持续个体与本次安装 → 内容核对 → 原表现协调入口 → 设备首帧 → 设备保存`。

确认记录独立保存安装编号、持续个体 `character_id`、设备、外壳、关联摘要、角色内容版本、可选方案引用和确认时间。配置关联与实际安装分别记录。磁场候选可帮助选择，手动确认可直接完成。

本轮执行范围是设备表情角色；人格和音色配置随记录保留，客户端采用接缝后续联合接入。页面显示“设备表情已保存”，完整角色采用按两边结果更新。

## 接口与依赖

| 接口 | 字段与结果 |
| --- | --- |
| `GET /api/shell-installation/state` | 记录修订、可选外壳、持续个体提示、设备实际表情与最近安装进度 |
| `POST …/confirm` | `installation_id / character_id / device_id / shell_id / binding_sha256 / plan_id / expected_revision`；保存主人确认，返回同一状态 |
| `POST …/retry` | `installation_id / expected_revision`；核对原记录后接续 |

沿用同源 JSON 与 `X-DeskBot-Studio: shell-installation-v1`。确认编号相同且内容一致时返回原记录，内容不同返回冲突。关联或资源版本变化后重新确认。一个安装记录属于一个持续个体；当前客户端已有绑定时沿用该个体。

依赖 `ShellCharacters` 的已确认关联、独立原子存档、`ShellSwitchAdapter` 的内容与执行回执、`PresentationCoordinator` 及唯一 USB 所有者。锁顺序：采样库 → 角色库 → 关联库 → 自动换角 → 安装服务 → 连接所有者。主人确认后自动模式暂停并保留原启用状态记录；已发请求先收尾。安装完成后，主人可从高级工具明确开启自动模式。

## 边界与验证

- 菜单、说话和睡眠期间等待；内容匹配且主页空闲后提交。连续确认以最新目标接续，已发送请求先收尾。
- 首帧和保存分开记录。断线或服务重开后发起新查询，收到更新的设备结果再接续；目标、实际与保存均匹配时记录查询依据，需重试时提供按钮。
- 角色内容配置或外壳关联更新后显示重新确认；正常设备切换独立记录。旧安装回执仍归原记录，最新确认保留为当前目标。
- 明确冲突后采用最新关联重新确认；回应丢失时沿用原安装编号核对。已发送请求即使遇到配置更新，也先核对实际结果。
- 单元覆盖手动确认、去重、版本冲突、内容缺失、等待、连续目标、断线与存档恢复；集成通过原 HTTP、生产 ControlLink 和内存设备；浏览器检查安装流程、状态与表单保留。结果由另一 AI 复核。
