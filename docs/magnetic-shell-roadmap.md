# 磁吸外壳识别路线

研究版本已经在部分实验构建中读取过底座磁场 XYZ 样本，并观察到不同位置存在可区分差异；这不等于上游官方固件默认通过 UART 输出 XYZ。下一步先确认当前 C61 版本和实际 `0x06` 帧，再建立可解释、可复现的档案流程：

1. 对上端、下端、移除状态分别采集稳定窗口，记录均值、范围、方差和样本数。
2. 使用置信度和 `known / unknown / detached / stale` 状态，不在噪声或过期样本上自动换人格。
3. 手动登记外壳：用户输入名称、外观备注和角色绑定；设备只保存稳定的传感器事实和档案 ID。
4. 双槽或版本化保存档案，断电恢复后验证校验和；识别失败保持当前角色，不覆盖已有档案。
5. 通过多次拆装验证后，才把识别结果发送给客户端，由客户端决定人格、音色、口癖和表情库。

本阶段不修改官方电机、DOA、摸头和睡眠流程，也不让磁铁移动直接打断语音，除非后续有明确的交互设计和独立验收。
