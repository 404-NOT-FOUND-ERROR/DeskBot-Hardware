# 磁场外壳识别 / Magnetic Shell Recognition

每个外壳具有独特但固定的磁铁布局。换壳导致磁场变化，设备输出置信度与已知/未知/歧义/不稳定/过期事实；用户确认后客户端才将物理外壳绑定角色。固件不猜测人格，不因移动磁铁直接登记。

当前 O2f2 使用有界 RAM 档案、稳定窗口与只读 MCP 查询，没有 NVS 持久化或登记设置页。A/B、移除、重新装回做过主机和历史设备实验；第三个真正固定布局 C 尚缺，不能把“磁铁拿近但移除”当有效新壳 C。底座维修期间只继续离线工具，不虚构传感器实测。

底座修好后：

1. 固定底座与环境，分别采集 A/B/C；训练与评估独立，记录方差、样本数、姿态与移除距离。
2. 重复拆装、静止、转头后恢复与外部金属干扰测试，统计误认和拒识。
3. 明确 `no_data / warming_up / known / unknown / ambiguous / unstable / stale` 及失联处理。
4. 通过后设计用户确认、档案 revision、删除/导出和断电恢复，再单独测试持久化。
5. 客户端负责 `magnet_profile_id → role_profile`；未知外壳询问、备注与角色演化不放在电机回调里。

`0x06` XYZ 是研究底座遥测扩展，不是已证明官方默认输出。完整阶段与回归要求见 [roadmap.md](roadmap.md)。
