# 工作台风格与角色包

日期：2026-11-11。目标：统一工作台与圆团节点预览的视觉和动效，同时确定换壳时的资源体验。

## 本轮实现

沿用 E3f-8 的页面、服务和角色接口。全站改用浅蓝底、白色面板、蓝紫强调色；表情选择用柔和色块，当前节点有轻量流光。大圆屏与节点使用原有播放时钟，界面动效使用统一缓动。保留深色模式、键盘焦点和减少动画设置。

同角色切表情时保留已显示的画面和节点，解析新目标后继续退出、进入；失败时保留最后成功画面并显示重试。换角色时同步更新名称和画面归属。普通页面以淡入和轻微位移衔接。动效层只控制视觉反馈，不改变资源、角色选择、USB 请求和调度优先级。

新增“角色包怎么装”说明，展示留存资源、双角色容量投影与建议线。数据来自已核对的资源清单：E1.45 为 5,981,260 B，圆团六种三段 EAF 去重后 1,244,597 B；加入平面索引的内存打包为 7,229,956 B，活动分区 8 MiB，建议线 7 MiB。此投影尚待加入正式角色图与布局。

依赖：现有构建器、角色目录与片段清单 → 页面静态数据 → 角色页与发布页容量说明。原有接口保持不变，新增样式与动效模块由构建器嵌入。浏览器检查覆盖六页面、快速切换时画面持续、暂停、深浅主题、键盘、320/390px 与减少动画；角色保存与解析沿用原回归，完成后独立复核。

## 推荐资源体验

**电脑保存完整素材库，设备常驻一到两套常用角色；新角色首次同步，已安装角色随换壳切换。** 常驻数量以最终包大小为准，不固定成两个等大的槽位。

| 使用场景 | 主人看到的体验 | 资源处理 |
| --- | --- | --- |
| 换上已安装角色的外壳 | 识别后切到对应角色 | 切换映射，直接使用已有资源 |
| 第一次使用新外壳 | 确认绑定，电脑预览角色，点击同步 | 计算包大小 → 安装 → 回读通过 → 启用设备角色 |
| 设备空间足够 | 保留当前常用角色，添加新角色 | 多角色共享一份资源包，按内容去重 |
| 空间接近建议线 | 给出精简可选动画或替换不常用角色的选项 | 先展示变化、保留内容和容量，再安装 |
| 未安装角色暂时没有电脑可用 | 显示“已识别，角色待同步”，继续使用当前角色 | 身份、绑定、记忆分别保留，待方便时同步 |
| 更新过程中断开 | 重连后显示进度与恢复入口 | 首版沿用电脑备份、回读、安装和恢复流程 |

角色包分为日常必备表情和可选表情。必备表情优先覆盖待机、开心、难过、害羞、困惑、困倦；聆听、系统提示及原有身体功能分别维护。没有独立素材的语义使用该角色明确登记的替代表达。重复素材按内容合并，保留进入、持续、退出的接点。低频动画进入电脑母库；下架之前先梳理对话、菜单、配件和动作的引用。

首次同步以 USB 连接电脑完成。将来可接本地无线同步，包格式和角色激活接口共用。双角色共存与双份更新分区是两件事：前者在同一活动包内共存，后者要另做分区、提交和启动恢复设计。当前 32 MiB 芯片还有规划空间，后续按实际需求评估用于更新暂存或资源扩展。

## 开发顺序

1. 本轮完成统一风格、持续预览和角色包容量说明。
2. 接入设备逐素材布局、角色片段图与三段调度；生成最终双角色包，精确计算容量。
3. 增加安装清单：已安装／待同步／可替换角色、必备／可选动画；明确列出空间和替换影响。
4. 沿用电脑备份与恢复流程，完成双角色切换和日常交互验收。
5. 外壳识别调用同一角色入口；再接人格、声音和对话。无线同步与设备更新暂存作为后续独立增量。
