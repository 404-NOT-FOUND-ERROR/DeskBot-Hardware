## 下一轮先完成什么

1. **双角色人工验收。** 设备切换、保存和执行回执已核对，主人比较两套画面、镜像、过渡及原交互；新素材转换与布局按需要接入。
2. **换壳自动切角色。** 完成固定布局重复拆装评估、档案保存与实时身份；主人确认外壳绑定后，复用手动切换的角色激活入口。
3. **角色对话。** 接客户端人格与语音服务，让同一角色档案同时决定声音、对话与表达。
4. **丰富与维护。** 扩充有授权或原创的素材、独立动作与组合，再加入记忆、反馈和角色演化。

先看到两套角色的区别，再让换壳触发切换，最后接通对应人格与声音。素材参考见 [Grok Bot 评估](grok-bot-source-review-20261111.md)。
