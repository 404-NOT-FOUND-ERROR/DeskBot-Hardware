## 现在开发什么

把电脑工作台与稳定固件接通：看见已装资源 → 修改角色接线 → 预览前后效果 → 安装选定资源 → 发送表情 → 查看回执。资源安装与后续 App 的顺序、回退已完成离线验证；接下来确认平静画面，再安装 E1.45 与 E3f-1，验收可重复的害羞表达。

## 设计依据

固件提供身体事实和表达能力；电脑选择角色并制作资源。语义与文件分开，角色配置不改变底座控制。EAF 活动区为 8 MiB，发布建议上限 7 MiB。当前设备 E1.18 资源保留，E1.45 只替换 `embarrassed` 的接线。

候选按显示查询 → 单个表情请求 → 真实目录组装。每层只增加对应功能，保留 E3c-3b 的 4,092 B SPI 分块和发送错误返回；USB 继续使用辅助控制台与每次读取一次、10 ms 间隔。新的读取预算作为独立增量。
