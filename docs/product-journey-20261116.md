# 完整产品体验评估

更新：2026-11-18。本页定义完整使用周期。[整体交付评估](project-readiness-20261118.md)核对当前实现与差距，[核心成长流程](product-experience-20261116.md)保留世界、愿望与换壳规则，[主线](project-mainline.md)记录执行顺序。

## 产品要成立的体验

用户认识一个在奇幻平行世界生活的个体。日常交流和现实信息影响它的处境，它作出自己的选择，逐渐形成偏好与愿望。主人可以参与、引导、商量，也可以安静地陪伴。偶尔的形象制作与实体换壳，让共同经历变得可见、可触摸；记忆与关系一直延续。

体验分成三种节奏：**每天有轻松的相处，隔一段时间能理解它的变化，偶尔一起完成一次实体成长。** 每种节奏都能独立带来价值，制作进度按主人的生活安排接续。

## 从认识到长期相处

| 旅程 | 用户要完成什么 | 产品应给出的反馈与交互 | 遇到中断，怎样继续 | 完成标志 |
| --- | --- | --- | --- | --- |
| 1. 认识产品 | 判断是否适合自己的桌面和生活 | 看一段日常、一次自主选择和一次换壳示例；了解联网、运行服务、费用与打印条件 | 先体验日常，制作条件可稍后准备 | 能说清它如何生活，以及自己需要准备什么 |
| 2. 开箱与准备 | 装好、供电，连上网络和所需服务 | 按实物提示装配；明确电源／电量、音量、麦克风、联网和服务就绪状态，保存设置进度 | 从未完成项继续；常见问题旁直接给出下一操作 | 知道已完成什么，能够启动第一次交流 |
| 3. 第一次相识 | 创建或找回同一个体，建立第一次共同经历 | 初次见面、名字与基础偏好讨论；用一个小事件展示它的世界和自己的选择 | 重开接续同一次相识；迁移用户先找回原个体 | 用户能理解“它是谁、在做什么、怎样和它相处” |
| 4. 每日相处 | 说话、触摸、看近况，也能专心做自己的事 | 聆听、思考、说话和打断有明确反馈；闲时有活动线索，重要近况适时分享 | 没听清可重说；长等待可取消，失败后保留输入和下一动作 | 一次交流顺畅完成，并接回原有生活 |
| 5. 离开与返回 | 安静离开，回来后快速接上 | 可主动说晚安或静音；回来先看到一条与实际记录相符的近况，再选择聊或继续忙 | 分别说明服务仍运行、设备离线和服务暂停的状态 | 用户知道它经历了什么，未完成活动能继续 |
| 6. 理解成长 | 看懂现实输入怎样影响它的选择 | 来源、世界事件、选择与结果能追溯；近况讲故事，详情可按需展开 | 暂停某类输入、忽略一次建议或隔几天再看，都能继续 | 用户能指出一次有来由的变化，角色仍有自己的取舍 |
| 7. 讨论愿望 | 决定支持、试一试、调整或以后再说 | 它讲清向往与经历；主人可提问、协商或暂缓，愿望保存为可接续事项 | 暂不制作时继续生活；兴趣改变时保留来由并重新商量 | 双方知道这次决定和下一步，生活继续推进 |
| 8. 设计与制作 | 看效果，理解能否做出，安排打印 | 概念图、圆屏与声音预览、可制造版本、材料／费用估计和装配说明放在同一项目 | 无打印条件可保留方案或寻求协助；失败从模型、打印或试装的对应步骤重试 | 得到适配硬件的模型、内容包和可执行的制作说明 |
| 9. 等待与试装 | 隔天接续，检查实物是否合适 | 展示已确认方案、实际制作进度与试装检查；它的生活照常推进 | 修改方案保留版本；返工接续当前项目，愿望变化另行协商 | 用户清楚手上的实物对应哪个方案，装配检查完成 |
| 10. 安装与采用 | 告诉它装好哪套，并看到一致变化 | 磁场候选或“我换好外壳了”进入确认；分别显示外壳确认、内容准备和实际采用 | 可更正候选、稍后处理或重试未完成项，保留已完成进度 | 实物、画面、声音和角色状态对应，记忆关系延续 |
| 11. 长期使用与维护 | 重用旧壳、换网、更新、换电脑或暂时停用 | 显示当前个体和实际版本；提供备份、找回、更新接续与旧版恢复入口 | 从最近有效记录恢复；暂停后可重新接续，迁移时核对原个体 | 用户能自行完成常见维护，回来仍认得同一个体 |

产品定位、开箱相识和长期间隔都进入评估；核心流程只承担其中的成长与实体化部分。

## 日常交互的基础规则（提案）

| 场景 | 用户能理解的表现 | 需要验证什么 |
| --- | --- | --- |
| 自己生活／待机 | 一眼能看出当前活动，交流可随时发起 | 闲时有生命感，长时间观看也适合桌面环境 |
| 正在听／没听清 | 及时回应唤醒；听取结束有提示，没听清给出重说入口 | 麦克风状态、触摸与语音起停一致 |
| 思考／说话／打断 | 等待有反馈；点击或约定口令可中止，之后回到合适状态 | 答语、字幕和表情属于同一轮，打断后原任务可接续 |
| 忙碌／安静／睡眠 | 用户可一键安静，选择时段和主动分享程度 | 重要近况适时呈现；未回应提示合并，恢复后按需查看 |
| 多端同时互动 | 当前会话和实际生效的表现清楚可见 | 一个个体、一份生活记录；手机、电脑和实体的反馈协调 |
| 未联网／服务暂停 | 显示当前可用能力、重连进度与继续入口 | 本地触摸、菜单、缓存表达逐项核对；世界推进按服务实际状态记录 |

主动性先以“安静生活、少量有意义分享、用户随时可参与”为试用方案。分享节奏依据相处观察调整；用户未回应时，后续近况汇总在同一入口。

离开返回区分三种事实：**服务在运行**时讲述已记录的经历；**设备离线而服务运行**时，重连后汇总最新近况；**服务整体停止**时，恢复已有进度。停机时段是否补算世界活动另行讨论，补算结果与实时记录分别保存。

愿望和制作项目分别管理。暂缓制作、模型返工或没有打印机，都能继续日常相处。打印期间兴趣变化时，由它与主人讨论保留原计划、调整版本或延期；具体触发规则留给愿望模块设计。

## 入口和服务如何衔接

- **桌宠本体**承接随手交流、即时反馈、轻量活动与安静控制；触摸和语音使用同一会话规则。
- **日常客户端**建议以“近况、交流、愿望与制作”为主入口。当前身份、实际形态和服务状态容易找到；设置中管理网络、来源、音量和恢复。
- **制作工作台**承接模型、表情、镜像、声音与发布。普通任务给出完成路径，参数、节点、采样和原日志按需展开。
- **生活服务**集中保存身份、经历、任务、关系与愿望；认知模块提出选择，服务记录执行结果，设备反馈实际表现。

设备状态、服务状态与项目进度共同形成“下一步做什么”。重复点击、断线和重新打开继续原任务；日常界面用可执行提示表达结果，详细原因留在诊断入口。输入来源逐项选择，麦克风工作和静音清楚可见，生活记录可查看和导出；删除或迁移时先说明对原个体记录的影响。

首批体验由项目协助联网、打印与问题处理，逐次记录需要人工帮助的步骤。日常入口的载体随联网原型确定：手机浏览器、已有客户端或圆屏按任务分工，普通交流由桌宠直接完成。

## 运行方式与实际成本

已确认日常目标是**桌宠联网就可相处，用户按需打开电脑**。后台仍需运行生活与模型服务。4a 的 HTTP／USB 首环验证共享状态与表达；设备联网接入和后台部署接续验证。

| 方案 | 用户体验与负担 | 接续验证 |
| --- | --- | --- |
| 开发电脑与 USB | 用于工程首环、内容制作与调试；日常目标另接设备网络 | 先核对身份、表达与恢复，再复用这些规则接入网络通道 |
| 家中常开小主机，设备联网 | 日常可离开电脑；增加主机准备、配网与维护 | 服务安装、自启动、局域网／外网连接、语音路由与设备身份接入 |
| 托管服务，设备联网 | 用户启动步骤更少；需要持续服务和费用安排 | 绑定找回、隔离存档、网络延迟、模型／语音成本与更新运维 |

首轮提案是由项目准备持续运行的生活服务，让体验者完成联网后直接相处；后台采用小主机或托管服务，按连通性、维护和成本选择。生活计算和模型调用所在位置分别说明。对比模型调用、ASR/TTS、常驻设备与打印耗材的真实用量，说明项目协助和用户操作的分工。

## 首版与开发顺序（提案）

**最小日常版**先让用户完成相识、一次一致的交流、一次离开返回和一次重开接续。**核心体验版**再让一个有来由的愿望走到可打印、可安装的实体变化。两次交付各自完成用户闭环。

交互、接口、依赖与联网拓扑见[最小日常版设计](daily-experience-v1-20261116.md)。P0 设计和有限 4b1 USB 首环已有，当前先组合真实交流入口，再接真机联网语音、身体反馈与常驻日常版。每位体验者独立实例和存档，主机按连通性、用量与维护需求选定。

| 顺序 | 交付重点 | 用户可观察的完成标准 |
| --- | --- | --- |
| P0 · 设计完成 | 完整旅程、少量体验者范围、日常交互与常驻服务方案 | 交互、接口、依赖与验收任务见最小日常版设计 |
| 4b1 · 首环已验收 | HTTP 文字到平静／开心 USB 表达，固定回复与原身份接续 | 四次交替播放与按钮、原有菜单／对话／触摸／睡眠正常，结果已归档 |
| 4b2 · 当前主任务 | 组合原存档、真实模型、安装采用和语音路线，再接设备 Wi-Fi、真人收音与发声 | 交流、字幕、表情与同一个体一致；可追问、打断和重连 |
| 4b3 · 最小日常版 | 实际身体事件与动作、常驻服务、离开返回、安静、首次引导与找回 | 关掉制作电脑后仍可交流互动；服务恢复接续原个体，连续运行、延迟与费用有记录 |
| 4c—4d · 愿望与设计 | 经历积累、协商和暂缓、概念图、修订及内容预览 | 用户理解向往，能够继续、调整或暂缓一份方案 |
| 5—6 · 核心体验版 | 参数化、打印协助、试装、等待接续、主人安装确认与实际采用 | 一份共同方案变成可用实体，记忆关系延续；旧壳可重用 |
| 7 · 长期迭代 | 更多生活内容、多源输入、使用观察、部署简化与可选自动匹配 | 新奇感、打扰程度、维护成本和持续使用意愿有实测依据 |

首次使用、网络状态和恢复从 4b 开始验收，阶段 7 侧重扩大使用与简化。3b3 磁场采样按原进度接续，为辅助提示提供依据；主人确认安装可单独推进。

## 怎样评估体验

首轮邀请主人与少量体验者，设置和打印可协助完成。观察任务包括：准备与第一次相识；关掉制作电脑后的日常交流及打断；忙碌时安静相处；离开返回；断网／换网／服务重开接续。记录是否独立完成、哪一步求助、是否误解当前状态、响应时间及实际运行费用。

成长阶段再观察：它的选择是否连贯又有差异，主人能否解释愿望来由，暂缓制作后是否仍愿意相处，打印失败能否继续项目，实体变化是否对应共同经历。通过实际相处收集“想再看看它做什么”与“太吵、太被动、太重复”的具体时刻，再调整节奏。

恢复与制作的技术验证分别覆盖重复操作、版本变化、退出重开、断线、更新恢复、模型装配与资源容量；实机继续核对画面、镜像、过渡、菜单、对话、触摸和睡眠。
