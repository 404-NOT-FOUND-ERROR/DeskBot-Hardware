# E3f-7：安装与回退

更新：2026-11-11。接续[常用表情离线结果](studio-common-e3f7-results.md)。

目标：将已验收的 E3f-5 / E1.45 升级为八项表情入口，保存可独立执行的 E3f-5 回退。

## 实现路径

接口沿用 `prepare / check / prepare-live / install / recover`。新增 E3f-7 版本适配器，固定候选、构建、测试、复核与 E3f-5 安装记录的摘要；复用现有 App 事务和 COM4 传输层。

数据流：E3f-5 安装与验收记录 → 重建完整参考 → 核对候选证据 → 生成离线计划 → 刷写前保存最新 NVS 并校验全片 → 写 App 与完整回读 → 核对启动身份 → 8777 重连、读取真实目录和八项能力 → 圆屏验收。

| 项目 | 本轮约定 |
| --- | --- |
| 候选 | E3f-7，4,521,872 B；使用 E1.45 资源 |
| 写入 | COM4，App 擦除范围 `0x10000..0x460000`，4,521,984 B |
| 保存 | 本轮现场快照、App 原字节、计划、执行日志与恢复入口 |
| 恢复 | 使用本轮原字节返回 E3f-5；保留恢复时的 NVS |
| 依赖 | 原 App 事务、已验收 E3f-5 安装、E3f-7 冻结构建与专项报告、8777 服务 |

恢复仅依赖同轮备份和计划，独立于候选、构建目录与历史安装记录。末扇区的 112 B 沿用本轮原字节。串口操作使用预检确认的 IDF Python 3.11；停止工作台串口观察后交接 COM4。

## 验证与交付

单元测试核对候选与证据、设备身份、参考资源、尾扇区、NVS 更新和计划边界；集成测试走生产安装事务，覆盖部分写入、回读与启动失败恢复、删除候选后独立恢复。另一位 AI 复核后执行现场安装。

安装后读取 37 项真实目录和八项播放能力，核对新会话与请求回执。主人方便时依次播放进食、平静、害羞及五个新表情，再检查菜单往返、对话中和结束后切菜单、摸头与睡眠唤醒。困倦表情与系统睡眠分别操作；附带动作按原目录观察。
