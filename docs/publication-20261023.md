# 公开发布范围 / Publication Scope

日期：2026-10-23。此次在独立 clone 中保留远程历史并正常提交，不 force push，不修改开发中的本机固件，不连接或刷写硬件。

## 包含

- 用户已验收 O2f2 的应用输入快照、固定配置、依赖锁和新的逐文件来源摘要。
- 当前主线、架构所有权与 UI 并发约束、功能结果、后续管线及验收闸门。
- 身体事实、磁场识别、角色绑定、审核登记、客户端传输契约与离线实现。
- 三个自包含工作台、绑定数据、原创 SVG 表达链路图与一个脱敏回放样例。
- EAF 编解码、压缩、播放器/包边界审计、主机检查与 CI；历史研究输入缺失的套件明确不属于默认可移植范围。

## 排除

完整 Flash/NVS、App 或资源分区回读、MAC/原始串口日志、Wi-Fi/API 凭据、私密回退、ESP-IDF 工具链、managed component 缓存、build 输出、无关客户端/游戏原型，以及绑定单台设备身份的操作脚本均不进入本次发布。

`firmware/base` 延续先前的部分历史增量，不声称等同当前 C61 完整工程。`gateway` 为早期骨架，不是正式客户端。历史 R9 保留在 Git 历史，当前 O2f2 不混入旧页面/通知/持久化模块。

## 公开副本与本机输入的差别

1. 本地组件依赖改为仓库相对路径；上游字体生成注释去除机器绝对路径，字形数据不改。
2. 删除已过时 R9 设置页与字体、旧配置和本机专用主机测试脚本；用 O2f2 输入替换而非叠加复制。
3. 协议示例真实设备 ID 替换成 `demo-device-a`；回放只有离线身份，不含芯片 MAC。
4. 节点工作台导航指向此次实际发布的两个页面；矩阵页增加禁止网络的 CSP。报告中的历史哈希不重写成“新验收证明”。
5. 默认 CI 只运行可移植套件；原 E1.4c 发布锁、角色绑定集成测试依赖固定上游 Git 对象与本机候选输入，需另行准备。历史相对 `tmp/` 路径作为输入标识保留，不是已打包文件承诺。
6. 外部 Emote Pack 候选素材授权待确认，公开 HTML 移除其派生图集并显示占位，保留原始哈希与研究结论；包含该预览的历史截图不发布。原始本机工作台未修改。`scripts/sanitize-public-previews.py` 记录这一包装步骤，历史报告不是公开 HTML 的新哈希证明。
