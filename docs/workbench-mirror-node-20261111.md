# 动画镜像选项

日期：2026-11-11。目标：自动填好镜像默认值，主人可以纠正，预览和生成包采用同一选择。

## 价值与界面

镜像是动画的显示设置。单独增加一个只读节点不能帮助纠错，因此取消该节点，在动画资源上提供“镜像”复选框和“恢复自动”。勾选后生成左右双眼，取消后居中显示一次。原片可展开对照，圆屏结果直接预览。

默认值来自素材的布局登记和生成信息；单眼默认勾选，完整脸默认取消。手动设置按角色、按资源保存，同一角色引用该资源的表情共同采用它。更换素材使用新素材的设置；撤销、重做、复制、保存和导入导出保留选择。聆听使用独立系统布局。

## 实现路径

草稿 `deskbot.studio_draft/v2` 在角色内增加 `mirror_overrides: {resource_id: boolean}`；未登记即自动。旧 v1 草稿载入时补空表。JS 编辑状态和 Python 校验使用同一规则。

数据流：自动默认／手动选择 → 预览与差异审阅 → 导出草稿 → 生成包中的 `deskbot-layout.json`。布局清单绑定资源名、摘要、尺寸和镜像值；打包后重新解包核对。服务端角色分析采用相同选择，与设备目录不同时显示需要同步。

当前 E3f-7 固件只按旧的固定布局播放。生成报告标注 `asset_layout_manifest_v1` 能力要求；E3f-9 接入通用布局清单后使用这些选择，再做实机验收。

2026-11-12：E3f-9a 已接入设备播放器和目录并通过双配置构建、独立复核及离线像素测试。预览现在按 GFX 整数居中和原始镜像覆盖次序绘制；E1.45 默认与单眼居中对照包已备好，实机安装接续进行。
