## 本轮实机修正

角色包保留中文字体、状态图标和唤醒模型，只替换表情。容量同时计算这些公共资源；8 色调色板保留 360×360、20 fps 和全部 29 种表情，使用原 4 位解码接口。

角色图与布局 JSON 使用独立 PSRAM 解析区，加载结束释放。原全局 JSON 分配器和显示线程继续沿用，避免大角色目录与 Wi-Fi 启动争用内部内存。测试覆盖公共资源引用、解析边界、旧包、菜单交接和成对恢复。

## 入口与恢复

工作台：`http://127.0.0.1:8782/#roles`。顶部播放设备当前角色，下方编辑素材与镜像；展开可查看全部 29 种。原有角色完整包位于 `artifacts/airboat-role-20261121/original-role/`。

本轮 App、资源及电脑配置恢复材料位于 `tmp/airboat-role-live-20261121-v3/`。恢复时先停止 USB 观察与日常后台，运行 `deploy-airboat-role.py recover --run airboat-role-live-20261121-v3`，回读和启动通过后再运行 `activate-airboat-host.py --restore --run airboat-role-live-20261121-v3`，按原配置重开两端服务。

本轮广泛历史测试中有两项 E3c 旧源码摘要断言与后续源码不一致，单独保留记录；本轮 50 项专项全部通过。
