# E3f-8：选择角色并记住它

日期：2026-11-11。目标：在现有工作台选择“原有角色”或“圆团”，重开页面和服务后恢复选择，同一种表情按所选角色解析。

## 实现设计

角色使用独立的表达目录，包含编号、名称、版本和六项语义映射。原有角色以 E1.45 真实目录为依据；圆团使用已核对的可组合 EAF。`neutral / happy / sad / embarrassed / confused / sleepy` 分别对应圆团的 `idle / happy / sad / shy / confused / drowsy`。

数据流：选择角色 → 激活服务保存选择 → 按当前角色解析语义 → 节点和圆屏预览。圆团经过进入、持续和退出；原有角色沿用逐素材布局、帧率和循环方式。编辑草稿保持独立，页面明确标注“正在编辑”。

| 接口 | 输入 | 输出 |
| --- | --- | --- |
| `GET /api/roles/state` | 无 | 当前角色、修订号、目录摘要和两套角色 |
| `POST /api/roles/activate` | `role_id, expected_revision, catalog_id` | 保存后的当前角色；并发修改返回最新状态 |
| `POST /api/roles/expression` | `semantic, expected_revision, catalog_id` | 当前角色对应的资源、布局和片段链 |

选择保存到项目 `tmp/deskbot-studio-state/active-role.json`，同一文件只有一个服务写入者。修订比较、临时文件写入和原子替换位于同一锁内；保存成功才更新内存。目录摘要指角色目录，与 USB 设备目录分别管理。重复启用同一角色仍先核对修订和目录，不增加修订号。目录变化或保存文件异常时，页面提供“重新保存角色”：`POST /api/roles/recover` 将原文件另存后保存选择，输入沿用激活接口。

服务关闭时等待正在保存的选择完成，再关闭写入入口、释放文件锁；重新启动从完成的保存记录读取。

角色激活和表达解析为独立模块。后续确认外壳身份后复用同一激活方法，外壳编号、磁场档案与角色编号各自管理。当前 HTTP 入口接收手动选择。

工作台沿用 E3f-7，新增角色页和顶部当前电脑角色提示；六个语义可连续预览，三段节点显示当前播放位置。切表情请求中保持当前画面与节点；成功解析后切到目标，失败时保持最后成功画面并提供重试。跨角色加载期间标出仍在显示的角色，等新角色场景准备好后整体切换。激活请求串行保存，过程中只保留最后目标；遇到其他页面修改则同步最新选择，由主人再次选择。所有角色解析来自服务返回的当前修订；旧回复在角色或页面变化后失效。多页面在重新聚焦时同步选择。

运行角色与编辑草稿独立；草稿替换、撤销和发布审阅不改变当前角色。原有角色的害羞取 `shy_candidate.eaf`、25 fps、循环、双眼镜像和附带 `cat_nuzzle`。跨角色切换从新角色的平静重新开始；圆团内部表达经过已验证的三段衔接。

两套角色共用独立的预览时钟和暂停状态，原有角色复用帧计算与镜像规则。作者草稿的暂停和逐帧操作单独管理。

[编辑页](http://127.0.0.1:8778/#editor)在动画资源内提供[镜像选项](workbench-mirror-node-20261111.md)，自动填好默认值，允许手动纠正和恢复自动。设置随当前角色草稿保存，圆屏预览、导出和生成包保持一致。原片可展开对照。运行角色页保留原有预览，Grok 素材接续正式角色图编辑。

本步交付电脑端保存和预览。页面显示“当前电脑角色”和“角色资源依据”；设备实时状态在既有连接页读取。容量面板分别显示电脑素材库、E1.45 留存资源和待同步角色的打包预估，正式角色图与布局加入后再给出设备安装结果。完整脸布局、设备三段调度和正式资源包接续下一步，USB 仍由既有连接模块统一管理。

## 测试与归档

单元测试：六项映射与摘要、首次保存、重启恢复、重复选择、并发修订、保存失败、异常文件及非法输入。HTTP 集成：真实保存和重启、来源与请求边界、角色变化后的旧解析、图片白名单；角色接口不调用串口。

浏览器：两角色和六语义、节点动画与布局、快速选择、迟到回复、刷新恢复、多页同步、存储失败提示、桌面与 390/320px 布局、减少动画。沿用原角色节点和播放调度回归，完成后由另一位 AI 复核。

## 后续顺序

角色选择与保存 → 完整脸布局和设备三段调度 → 正式双角色资源包与容量核对 → 实机切换验收 → 外壳自动选择 → 人格、声音和对话。

## 使用与结果

运行 `scripts/start-deskbot-studio-e3f8.ps1`，打开 [角色页](http://127.0.0.1:8778/#roles)。点选原有角色或圆团，再选六种表情；选择自动保存。圆团的三段节点与大圆屏同步，暂停同时控制二者。原有节点草稿编辑折叠在页面底部。

15 项单元、11 项生产 HTTP、40 项浏览器检查通过，另有 17 项原布局与 9 项片段调度回归通过。本机和公开页面重建一致，桌面及 390/320px 页面已查看。测试使用临时选择文件；设备保持 E3f-7 / E1.45。

设计与实现经另一位 AI 复核。复核中修正了预览时钟互相影响及服务关闭期间的保存竞争，并添加回归。记录位于 `tmp/deskbot-studio-e3f8-20261111/qa/`。

运行环境：服务和 HTTP 测试使用预检确认的 Python 3.13，含 `jsonschema`；Pillow/NumPy 随附 Python 用于素材生成。Node 测试沿用现有 Playwright 和 Edge。先检查依赖，再运行对应入口。
