# 开发路线

更新：2026-11-05。当前处于阶段三“电脑连接身体”。[完整计划](development-plan-20261104.md)说明产品链路，[当前主线](project-mainline.md)列出最近任务。

```mermaid
flowchart LR
    A[身体与资源基础\n已完成迁移] --> B[表达工作台\n阶段二完成]
    B --> C[电脑连接身体\n阶段三进行中]
    D[底座修复] --> E[外壳识别与登记]
    C --> F[角色最小闭环]
    E --> F
    F --> G[DeepSeek、语音与角色演化]
```

| 阶段 | 工作内容 | 完成效果 |
| --- | --- | --- |
| 1. 身体与资源 | 原有交互、容量核对、8 MiB 资源迁移、新表情 | 原交互正常，资源可恢复，新表情按预览播放 |
| 2. 表达工作台 | 节点预览、角色草稿、可复现打包、容量核对、请求模拟 | 替换前后与影响范围清晰，可生成选定资源包；已完成 |
| 3. 电脑连接身体 | USB 身份、会话、状态、一个表情、真实目录和动作 | 点击表达后设备执行并返回结果，断开重连可恢复 |
| 4. 外壳登记 | 固定磁铁布局、独立评估、拆装恢复、持久档案 | 识别已知壳；未知壳可确认、命名和登记 |
| 5. 角色闭环 | 外壳编号、主人确认、角色配置和当前角色显示 | 换壳后角色及表达映射一致更新 |
| 6. 服务与演化 | DeepSeek、语音识别与合成、角色愿望和反馈 | 自然对话、角色音色与表达、提出换装愿望 |

## 验证方法

每轮定义一个功能，依次完成离线测试、独立构建与产物比较、备份与部署、实机验收。UI 回归覆盖对话中及结束后切菜单、摸头和睡眠唤醒；接口覆盖重复请求、超时、断开和重连。

阶段结果保存在[更新日志](../CHANGELOG.md)、[当前基线](baseline-status.md)和对应阶段文档；原始报告保留各阶段执行时的状态。
