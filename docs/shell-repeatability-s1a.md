# S1a：固定布局外壳评估

目标：同一外壳多次装回后仍能识别，取下或未知布局有独立结果。本轮先完成电脑回放工具，设备保持 E3f-9d.1，双角色画面由主人晚上验收。

## 实现

`evaluate_suite(path, root)` 读取一份 JSON 清单，返回评估报告。清单给出识别参数、训练/评估/观察日志、物理装配编号和人工预期。单个日志使用现有采集格式：带时区时间、制表符、COM4 的 `cmd=06` 回调。

数据流：原日志 → 既有磁场解码器 → 既有 M2 识别器 → 每次装回结果、误认与待补样本。训练显式登记；评估重新开始采样窗口并保留训练档案。参数沿用 M2 默认值并完整写入报告。

训练和评估使用不同装配编号、独立时间段与样本。`mount_id` 在整份清单内代表一次实际装配；同一装配跨批次录制仍计一次，`capture_id` 只标识采集批次。每个已登记布局目标至少 10 次独立装回。取下和未登记布局分别统计，各以 10 次为采样目标；M2 继续回报原有识别状态。报告记录每次最终状态和期间误认，分别展示识别结果与采样覆盖，距离和相似度按原算法定义展示。

接口：`scripts/evaluate-shell-repeatability.py --suite <清单> --output <项目内新目录>`，生成 `report.json` 和简洁预览页。输入、输出限本项目路径；输出目录独立新建。

依赖：Python 标准库、`protocol.magnetic_telemetry`、`protocol.magnetic_recognition`。本轮不增加固件配置或串口所有者；自动角色切换后续复用现有启用接口。

## 验证

单元覆盖：独立样本、重复装配计数、训练评估混用、非法时间与传感器、已知/未知/歧义/不稳定、缺样本、输入路径和数量边界。集成从真实日志解码，经生产识别器到 CLI 报告；用维修后的“上移训练、装回评估、取下拒识”记录做一次回放。

## 本轮结果

电脑工具已完成。11 月 7 日的滑块上、下位置用于历史回放：上移位置训练后的独立装回识别正确，取下记录全程没有误认已登记布局。两项各计 1 次；下移位置和未登记布局各有 0 次评估。基线段只作观察。这些记录用于复现工具，固定外壳的重复拆装接续现场采集。

28 项专项测试、31 项识别与遥测回归、16 项采集链回归全部通过。独立复核补齐了跨采集批次的装配计数：同一装配只计一次，训练装配与评估装配分别核对。原参数和日志摘要随[回放报告](../artifacts/shell-repeatability-s1a-20261112/report.json)保存，[预览页](../artifacts/shell-repeatability-s1a-20261112/index.html)展示每组已测与待补次数。采样覆盖和匹配结果分别记录；没有评估样本时，匹配结果为未完成。

接续顺序：双角色画面验收 → 固定外壳独立采集 → 拆装评估 → 档案保存 → 外壳绑定角色。当前设备继续用于晚间双角色验收。
