# 当前成果与验证边界

记录日期：2026-10-12。设备最后刷入 R9 display-rollback；当前公开源码经过字体许可整理，未发布固件二进制，也没有完成本轮实机验收。

| 模块 | 已保存的成果 | 当前边界 |
| --- | --- | --- |
| 官方身体能力 | 语音、双麦 DOA、摸头、电机控制入口、表情、睡眠/唤醒和产品 UI 源码 | 作为回归对象；R9 尚待菜单与对话回归，不能声称稳定修复 |
| 底座事件 | 独立语义映射、连接和机械状态去重、最近 24 条日志、只读查询与页面 | 使用官方 UART 接收器；动作完成不虚构请求 ID |
| 磁场遥测 | XYZ 快照和圆屏展示 | 依赖 C61 研究遥测扩展；官方底座默认协议不能直接视为具备该数据 |
| 外壳识别 | 稳定窗口、置信度、已知/未知状态、档案保存和只读诊断 | 历史实验已验证登记/重启恢复；当前候选需重新回归，不自动换人格 |
| C61 增量 | 电机、磁吸传感器与 UART 的历史源码差异 | 仅发布部分修改文件和补丁；并非完整底座工程，不能直接刷写 |
| 表情/动作工具 | 资源清单导出、候选包校验、容量检查、绑定及动作时间线模拟 | 完全离线；预览不会执行硬件动作，不代表已实现运行时热替换 |
| 客户端接口 | 身体事实事件 schema、文本网关原型 | 协议草案；未接通正式客户端的 DeepSeek、ASR、TTS、人格与记忆链路 |
| 工程检查 | 主机协议/状态测试、格式兼容性检查、独立构建脚本、来源和许可证记录 | 主机测试与源码检查不替代 ESP-IDF 构建及实机验收 |

本次归档不新增设备行为。下一轮先验收 R9 的菜单、对话、摸头、声源跟随和底座动作；确认显示问题消失后，再逐项恢复或验证只读诊断、磁场识别与客户端接口。客户端负责角色意义、人格、音色和口癖，固件负责身体事实及能力执行。
