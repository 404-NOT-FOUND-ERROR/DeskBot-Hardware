# 功能与成果 / Feature Inventory

记录：2026-10-24。以 [baseline-status.md](baseline-status.md) 为当前设备锚点；旧 R9 不再是当前版本。

| 功能 | 现状 | 证据边界 / Limit |
| --- | --- | --- |
| 官方小智语音、UI、摸头、睡眠/唤醒、双麦 DOA 与动作 | O2f2 用户验收通过 | 不因一次构建或新资源部署自动延续验收 |
| 官方 UART 接收与副作用 | 原接收器继续处理滑动、配对、校准、配件 | 没有第二套设备 UART 接收器 |
| 底座语义/事件环 | 边沿去重、最近 24 条、原始字段与规范化帧、只读查询 | 高频磁场/心跳不刷事件；无新动作工具 |
| XYZ 遥测 | 研究 `0x06` 帧接入有界快照 | 要求匹配底座研究版本，不是官方默认输出 |
| 外壳识别 | 稳定窗口、置信度、RAM 档案、只读 identity/list | 无 NVS、无登记设置页；重启清空是当前设计 |
| 磁场主机实验 | A/B、近距离移除与重新装回有历史实验记录 | 真正固定布局 C 暂缺；环境漂移、运动与拆装仍需扩展 |
| 客户端契约 E1.5–E1.8 | 身体事实消费、角色映射、用户登记审核、记录接收器离线实现 | 不是设备实时连接，不触发人格或硬件 |
| 表达母库与 EAF | 当前设备 EAF 与新示例格式差异、压缩与播放器边界研究 | 不直接刷入新播放器示例 `.bin` |
| 节点工作台 E1.4d | 源码绑定与候选覆盖分层；圆屏预览与动作分支 | 静态关系，不是实时 trace；害羞候选仅预览 |
| 绑定矩阵 E1.9 | 复用统计、触发入口、待审查资源 | “未发现使用”不是删除许可 |
| E1.10–E1.12 | 无损压缩对照、播放器审计、隔离构建 | 构建输出不是自动部署授权 |
| E1.13 | `insert/eat` 资源部署、完整回读和本体交互回归均通过用户验收 | 只优化原动画；底座维修后的 C61 实测和客户端仍分阶段 |
| 未来角色与服务 | 客户端选人格/音色，固件输出身体事实并表现 | DeepSeek/TTS 替换与角色驱动尚未贯通 |

当前没有新增研究设置页面。历史页面、持久化、通知/行为实验保留在 Git 历史而不是混入当前基线。旧测试和工具有各自前置条件，见 [tests/README.md](../tests/README.md)。
