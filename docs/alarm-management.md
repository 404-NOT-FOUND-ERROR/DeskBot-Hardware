# 语音闹钟管理

当前固件把每日睡眠结束时间默认显示为 08:00，但不会自动启用提醒。升级时会把旧版没有明确设置的隐式 08:00 状态迁移为关闭；主人明确设置或拖动时间后才启用并保存。

小智可调用 `self.alarm.list` 查询每日睡眠提醒和番茄钟状态；`self.alarm.cancel` 接收 `sleep`、`pomodoro` 或 `all`。每日时间、启用状态写入独立 `deskbot_alarm` NVS 命名空间，不影响联网凭据、角色或其他 NVS。取消操作会真实停止提醒并在必要时回到主页。番茄钟离开页面后仍继续倒计时，查询结果与实际剩余时间一致。

语音暂停／继续番茄钟不依赖当前页面；它操作同一计时器，保留当前画面。测试直接执行生产计时回调，覆盖离开页面后倒计时、到点一次提醒、取消后不再提醒，以及未启用每日闹钟时的页面刷新。安装复用现有现场回读、回退与启动核验流程，并把新固件同步为表情工作台的安装基线。
