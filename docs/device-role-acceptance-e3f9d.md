# 双角色实机验收 · E3f-9d

目标：在同一桌宠上切换“原有角色”和“圆团”，播放对应表情，重启后保留选择。角色草稿继续用于编辑；页面上方的设备角色卡显示实际生效结果。

## 操作

打开 <http://127.0.0.1:8779/#roles>，让桌宠回到主页待机并结束对话。首次连接或重启后，到设备连接页选择 COM4，连接只读观察并启用状态查询，再回角色页。

“切换目标”是准备采用的角色，“已生效”是已处理首帧的角色，“选择已保存”表示重启可恢复。等保存完成再断电。

1. 在“桌宠当前角色”卡启用圆团，等“已生效”显示圆团。依次播放开心、难过、害羞，每项看几秒。
2. 启用原有角色，重复三种表情。比较完整画面、镜像和过渡。
3. 两个角色来回切换两次，观察衔接与页面状态是否一致。
4. 选圆团并等“选择已保存”。重新开机，再连接工作台并启用查询；检查仍是圆团。
5. 测菜单往返五次，对话中及结束后各切菜单，摸头三次，按设备现有方式睡眠再唤醒。困倦表情与系统睡眠分别记录。

每项完成后统一反馈；按自己的节奏操作。
