# E3d-2b 设备真实表情目录

目标：工作台读取桌宠实际安装的目录，清楚展示“语义 → 动画文件 → 播放参数 → 原动作绑定”。E3c-5b 经主人确认当前使用正常，作为本轮回退版本；此前花屏照片与记录保留。

## 接口与数据流

资源挂载成功 → 资源所有者生成 PSRAM 快照 → 原 USB 任务逐页回复 → 电脑收齐并核对摘要 → 工作台显示真实目录。目录最多 128 项、每页 2 项；沿用 `deskbot.studio_catalog_page/v1`，绑定设备、启动号、连接和会话。

资源所有者在启动路径同步构建快照，卸载资源前先使目录失效；构建失败时返回 `catalog_unavailable`。代次检查拦截旧构建结果，原资源的使用期由资源所有者管理。USB 在锁内复制页面，回复只使用副本。

工作台沿用“启用状态查询 → 读取实时目录”，同一时刻一条请求。读取期间连续分页，完成后恢复显示查询；重连后重新读取。目录展示已安装能力，表情发送仍使用现有单个 `neutral` 接口。

## 实现与依赖

复用 `studio-stable-ladder-20261108/catalog` 的双配置构建、原生 C++ 目录测试、生产工作台与部署事务。新增独立部署入口 `deploy-e3d2b-catalog.py`，提供 `prepare / check / prepare-live / install / recover / restart`。冻结固件按当轮源码与构建报告核对，当前电脑端另跑本轮测试。

App 为 4,517,936 B，分区余量 1,626,064 B；内部静态数据为 65,136 B，比 E3c-5b 增加 2,080 B。目录快照最多 69,632 B，位于 PSRAM；cJSON 的小节点仍可能使用内部堆。主任务栈为 8,192 B，USB 栈为 6,144 B，最大单函数栈为 1,392 B；按调用链核对余量，实机记录目录 `build_ms` 和可观测的内部堆最低余量。沿用现有显示补丁、USB 接收节奏与任务。

现场写入 COM4 的 App 并集 `[0x10000, 0x460000)`，共 4,521,984 B。准备时保存当轮 NVS 和回退字节，安装后核对完整 App、其余区域及启动。恢复沿用当轮计划，独立于候选和构建目录。

## 验证与交付

- 单元与原生集成：目录内容、边界、损坏资源、分页、摘要、会话变化和生产适配器。
- 部署集成：固定候选、实时 NVS、精确擦除并集、写入/回读/启动失败恢复，以及候选删除后的恢复。
- 实机：读取完整目录，与 E1.18 的 36 项快照逐项比较；断开重连后重读；目录读取后验证一次平静请求及回执。
- 日常操作：菜单往返、对话中与结束后切菜单、摸头、睡眠再唤醒；主人方便时统一反馈。

通过后继续资源读取专项 → E1.45 害羞表情替换 → 角色接线 → 更多表情与动作。外壳识别按独立模块接续。

## 电脑验证结果

候选的 20 项原生测试、20 项部署测试和独立 AI 复核通过；离线准备与检查通过。首次清单检查增加了延迟导入的解析器，首次部署准备发现快照摘要引用有误，两次记录均保留，修订结果分别见 `native-validation-2.json` 与 `deployment-validation-2.json`。

## 实机结果

COM4 已安装并完成 App 全量回读、其余区域摘要、NVS 和启动核对。生产工作台两次读取目录，每次 18 页、36 项、约 65 秒，与 E1.18 完全一致；重连生成新会话。目录含 28 个表情语义、5 种动作、1 个聆听动画和 2 个布局，使用 18 个独立 EAF。

一次平静请求在约 8.8 秒内收到同编号的 `accepted / dispatched`。联网重启后身份核对、目录构建与再次读取通过；目录构建 1,141 ms，快照为 68,296 B PSRAM。重启后观测到内部空闲 24,583 B，最低空闲 10,616 B；这是本轮负载的观测值。

两轮目录采集属于同一次启动；安装首启与目录采集之间另发生了一次重启，原因未保存在采集记录中。各段设备与 App 身份一致，联网重启后的记录另行关联，见[启动关联](../artifacts/studio-catalog-e3d2b-20261108/boot-association.json)。

主人已确认本轮日常测试均正常：菜单往返、对话中及结束后切菜单、摸头、睡眠再唤醒，见[交互验收](../artifacts/studio-catalog-e3d2b-20261108/manual-acceptance-followup.json)。本阶段完成。下一步做资源读取专项，再验收 E1.45 害羞表情替换和角色表达映射。恢复命令为 `deploy-e3d2b-catalog.py recover --run e3c-live-20261108-e3d2b-live1`，恢复本轮保存的 E3c-5b。
