# DeskBot base firmware snapshot

这里是 DeskBot 旋转底座（ESP-VoCat Base / ESP32-C61）的公开研究快照。它用于记录底座协议、磁场遥测和外壳识别的增量，**不是一个已经确认可以独立构建和刷写的完整底座工程**。

## 当前发布范围

- `source/`：当前公开的部分底座源码快照，包含与研究相关的控制串口、步进电机和磁吸检测文件。
- `patches/working-tree.diff`：相对于上游提交的工作树差异，包含诊断状态、限速磁场样本（`0x06`）等实验改动。
- `UPSTREAM.md`：上游仓库、提交和发布边界说明。
- `LICENSE`：底座上游 Apache License 2.0 副本。

由于没有随仓库发布完整上游工程、所有依赖、构建配置、生成文件和设备配置，不能从本目录直接推断“可构建”或“可刷写”。不要把 `source/` 与 `working-tree.diff` 拼接后直接烧录到 C61。

## 与本体的关系

底座 C61 与本体 ESP32-S3 是两个独立固件。底座负责磁场采样、磁吸事件、步进电机和回零；本体负责官方语音、双麦声源跟随、摸头、表情、显示和 UART 事实镜像。底座增量必须先在独立 C61 构建和设备上验证，再由本体消费。

`0x06` 是本项目实验遥测扩展，并非上游协议中已确认存在的官方 XYZ 输出。使用前要确认所用 C61 构建包含该扩展，并完成帧、频率和负载验证；高频样本不应直接刷事件列表。`source/` 内保留的上游说明只用于参考，不能当作本公开目录的完整构建说明。

## 安全边界

- 不提交完整 Flash、NVS、Wi-Fi/API 凭据或带芯片 MAC 的日志。
- 不在没有确认 C61 串口、分区和回滚镜像的情况下刷写。
- 任何底座改动都要单独构建、回读校验并验证回零、滑动、配件、动作完成和断线恢复。
- 该目录的公开内容只作为研究记录和补丁审计输入，不能替代上游完整源码。
