# 安装配置接入聊天与声音

日期：2026-11-18。接续已运行的安装同步，完成客户端的人格提示与音色采用。

## 目标与规则

主人确认外壳、设备保存并同步后，下一次交流使用对应形态的表达提示和已支持音色。持续个体、长期人格、记忆、关系和成长阶段由客户端原记录承接。

- 人格字段作为当前形态的表达提示，与客户端生活上下文共同参与原提示词。
- 每回合开始时冻结安装编号、配置版本和音色；中途换壳从下一回合采用。
- 空人格、未配置音色沿用原设置。已配置但服务不支持的音色显示具体原因，文字交流继续。
- 对话与语音识别入口共用原聊天编排。字幕、表达和合成使用同一份回答。
- `character_id` 是持续个体；`shell_id` 是实体外壳；`role_id` 是形态档案；`expression_role_id` 是设备表情图。四者不互相替代。
- 聊天在首次接收时保存配置快照，且先于模型、天气和语音等异步工作。相同回合重试或进程重开沿用原快照。
- 语音在 `listen.start` 冻结安装编号；识别时服务端按编号读取已接收并校验的安装档案。客户端不提交人格或音色正文。
- 安装编号省略时读取当前档案；显式 `null` 表示录音开始时无安装，整句话沿用原配置。指定编号找不到时返回 `installed_presentation_missing`。
- 配置快照、原对话、记忆与关系使用同一个持续个体，不因角色或外壳切换而迁移或重建。

## 接口与数据流

`主人确认安装 → 设备保存 → 原安装接收器 → 回合配置快照 → 原提示词／原 TTS → 原对话档案与输出队列`。

聊天按 `character_id + device_id` 读取当前安装；语音额外携带 `listen.start` 时冻结的 `installation_id`，服务端从接收器的安装历史读取对应版本。快照以 `turn_id` 写入 `chat.turn-presentations`，在首次 `await` 前持久化。

| 接口 | 约定 |
| --- | --- |
| `createInstalledPresentationResolver({getInstallation, voiceCatalog})` | 从接收器读取当前安装或指定安装历史；按个体与设备校验身份 |
| `resolve({character_id, device_id, installation_id})` | 同步返回限长、冻结快照；包括安装/配置摘要、形态提示和音色适配结果 |
| `createDeskBotServer({resolveInstalledPresentation})` | 可选注入解析器；聊天、ASR 最终结果共用同一个解析入口 |
| `turn.installed_presentation` | 保存角色、外壳、配置摘要、persona、安装编号及音色选择，供去重与重开恢复 |
| `turn.presentation_adoption` | 记录提示词采用、音色请求/实际结果；不支持时记录原因及采用的既有音色 |
| `listen.start → turn.presentation_installation_id` | 语音会话只传安装编号；接收器按编号返回已验证档案，ASR 不能覆盖档案字段 |

音色目录使用 `provider + voice_id` 明确映射到 TTS 服务参数。映射项说明支持的服务、实际音色名和说话风格。说话风格进入表达提示；声音风格是否生效按合成服务能力记录。回合分别保存映射、合成请求和服务实际回报；未合成、服务不匹配与实际音色不符分别标记。小智云音色接通对应服务后加入目录。

原客户端 TTS 结果随回合持久保存；外部小智语音合成发生在原 HTTP 回合之后，实际音色记录在语音会话报告。本轮交付离线模块、补丁和验证结果，运行中的客户端接续下一轮启用。

## 依赖与实现范围

沿用客户端 `0d8d4c5` 与已复核 4b1a 恢复补丁、原 HTTP／SQLite、安装接收器及输出队列。新接口以独立模块和小型补丁交付，在独立客户端目录和存档联测。当前 A/B 空配置继续使用现有设置。

本轮同时提供 Windows 中文音色适配，复用已核对的 `System.Speech` 与 Node 24。先查询已安装音色，再合成验证；测试输出留在本地。

## 验证与交付

单元覆盖空配置、唯一／多设备选择、四种身份字段、配置摘要、支持／未支持音色及冻结快照。集成用原 HTTP／SQLite 验证 A→B→A、对话中换壳、语音 `listen.start` 冻结、重复与进程重开恢复，并比较原生活档案。真实合成核对实际音色、回答文字与音频一致。

110 项测试通过：客户端与恢复 38 项、安装与采用 34 项、语音会话与原客户端 38 项。包括 A→B 中途切换、无安装冻结、prepared / output_enqueued 重开恢复、旧个体编号与 Windows 指定音色合成。补丁从已复核 4b1a 副本重建，重复应用、恢复依赖、仓库根目录及源码摘要核对通过。

结果见 [report.json](../artifacts/client-role-adoption-20261118/report.json)，接入方法见[交付包](../integrations/client-role-adoption/README.md)。独立复核记录随同归档。下一步：原启动器组合解析器与采用状态 → 角色内容 → 制作项目；真实外壳完成后做拆装校准。
