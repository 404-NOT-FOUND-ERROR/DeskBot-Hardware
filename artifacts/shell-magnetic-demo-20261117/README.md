# A/B 模拟磁铁 Demo

采用主人确认的最后一轮安静菜单静置样本：A 160 条，B 159 条，分别关联圆团和原有角色。

打开 `index.html` 可演练 A/B 候选、主人确认、手动调整与未知信号。演示选择只保存在页面中，实际安装使用页面中的工作台入口。

- `report.json`：数据概况、候选回放和接续流程。
- `profiles.json`、`project.json`：登记档案与关联草稿。
- `fixture-a/`、`fixture-b/`：带原时间的本体日志、状态标记、采集摘要与窗口说明。
- `formal-assessment.json`：保留原评估的实际覆盖数。
- `body-restored.json`：采集后工作台连接与设备身份。
- `tests.json`、`peer-review.md`：模块测试和独立复核结果。
- `browser-tests.json`：演示页 23 项浏览器检查，含窄屏、减少动画与零设备请求。

`fixture-*/body.log` 是标记窗口切片；同目录 `summary.json` 描述完整采集批次，两者计数范围分别保存。回放使用登记样本，用于候选演示。真实外壳完成后补独立拆装、移除与未知布局测试。操作记录见 `docs/shell-field-calibration-20261117.md`。
