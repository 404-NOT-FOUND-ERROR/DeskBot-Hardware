# E3f-9b 独立复核

日期：2026-11-12。范围：统一角色包设计、现有播放器、资源打包器与布局清单接口。设备和构建未操作。

## 设计复核

两角色共用素材、镜像选项、节点预览和打包的方向符合主线。实现时落实以下规则：

1. 明确三段组合的循环选项。现有 `GrokRoleScheduler` 会持续循环，尚无单次播放规则；界面可先固定循环，或补齐单次播放和测试。
2. 镜像后的接点检查覆盖同一组合及不同表情之间的共用起止帧。各表情的镜像不同，也可能影响切换。
3. 两角色包的布局 `role_id` 定义为包标识。遵守设备清单的 64 项、32 KiB，以及 EAF 文件名格式限制。
4. 内容相同而镜像不同的资源保留独立数据区。设备按数据地址及长度匹配布局，不能让两种布局共用地址。
5. 从 E1.45 实际基线组包，并核对原成员逐字节保留。现有单角色打包器固定 E1.18，不能直接沿用其基线和索引修改规则。
6. 草稿接口严格检查字段、引用和输入大小，生成固定摘要命名的产物。

设计已补齐：单段与三段各自替换；三段固定循环；同角色三段采用一致镜像；清单使用包标识并由角色图引用摘要；不同布局保留独立物理区间。设计复核通过，以上规则纳入实现核对。

## 实现复核

复核通过，未发现阻断项。已检查打包模块、生产 HTTP 服务、工作台、生成器与对应测试。

- E1.45 原成员逐字节保留；双角色引用、镜像清单与下载文件摘要一致。异镜像别名在真实包内使用独立偏移。
- 预览采用草稿帧率和循环；三段按退出、共享姿态、进入接续。资源支持手动镜像、恢复自动、撤销和重做。
- 替换显示原连接与新连接，并可恢复原连接。编辑选择独立于包的默认启用角色。
- 生成文件完整写入后提交；磁盘写入故障可重试。界面显示草稿是否成功保存。

独立运行 13 项单元与 4 项 HTTP 集成测试，17 项全部通过。核对本轮 42 项浏览器检查结果及桌面、850 像素宽截图，脚本错误与设备请求均为零；包含真实导入导出、播放设置生效、三段切换、保存恢复和包内对照。

本步交付电脑编辑与离线角色包。设备角色图和三段播放由 E3f-9c/d 接续；本轮未刷写、未做设备画面验收。
